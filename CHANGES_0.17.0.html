대상을 쉽게 선택하고,
미완성 작업도 저장해 이어서 만드세요.

이미지 선택·녹화·초안 저장을 개선하고 복잡한 반복 작업의 범위를 늘렸습니다. 배포 파일과 공개 상태는 0.17.0 Release 안내에서 확인하세요.

이미지에서는 누를 곳을 한 번 클릭하세요

프로세스 편집창의 화면 선택에서 누를 곳을 클릭하거나 영역을 드래그합니다. 선택한 입력 위치는 유지하면서 주변 이름·그림을 자동으로 확인합니다. 동일한 실행 버튼이 반복되는 경우 행 이름처럼 구별할 수 있는 부분을 함께 찾습니다.

여전히 구별할 수 없으면 선택을 유지한 채 필요한 범위를 안내합니다. 요소 정보가 확인되는 작은 버튼은 그림의 세부 정보가 부족하다는 이유만으로 요소 선택을 막지 않습니다. 캡처에서 구별되었다는 사실이 이후 모든 화면에서의 인식 성공을 보장하지는 않습니다.

녹화에서 실제 입력과 팝업을 함께 확인합니다

  • 입력 직전 화면을 보관하고 이미지 비교는 별도 처리하여 클릭을 기록하는 경로의 부담을 줄였습니다. 실제 앱에서의 전체 시간 개선율은 측정하지 않았습니다.
  • 누를 위치가 가려진 경우와 주변 인식 영역 일부만 가려진 경우를 구분합니다. 주변 영역은 조정할 수 있지만 가려진 입력점을 다른 위치로 옮기지 않습니다.
  • 소유 관계가 확인된 팝업이 나타나면 캡처를 빠르게 준비하고, 확인된 체크 상태·목록 선택값을 기록에 반영합니다. 같은 프로그램이라는 이유만으로 관계없는 창을 허용하지 않습니다.
  • 큰 화면이나 이미지 용량 때문에 기록을 더 보관할 수 없으면 앞부분과 동작 순서를 남기고 멈춥니다. 보완이 필요한 단계는 표시되며 조용히 삭제되지 않습니다.

녹화는 동영상 저장이 아니라 사용자가 실제로 수행한 클릭·입력을 단계로 만드는 기능입니다. 녹화 중 동작은 실제 프로그램에 적용됩니다.

문제가 남아 있어도 초안으로 저장하세요

빠진 대상이나 확인할 경고가 있으면 저장 버튼이 초안 저장 · 이어서 수정으로 표시됩니다. 같은 프로세스를 나중에 다시 열어 필요한 단계만 고칠 수 있습니다. 다시 녹화하거나 전체 작업을 지울 필요가 없습니다.

미완성 초안은 실행·스킬 내보내기를 막습니다. 필요한 단계를 보완하고 녹화 경고를 확인한 뒤 저장하면 실행 가능한 작업이 됩니다. 대상 지정 문제를 해결한 경우 해당 경고를 정리하지만, 누락된 동작이 복구되었다고 임의로 판단하지 않습니다.

위와 같은 작업은 총 5,000단계로 펼쳐 실행하며 사용자가 같은 동작을 모두 복사할 필요가 없습니다. 중첩·무한 반복은 지원하지 않고, 이미지·파일 용량 제한은 별도로 유지합니다.

긴 저장 작업은 100단계 또는 약 45초마다 완료 지점을 보관합니다. 연결의 시간·조작 횟수 범위가 끝나면 다음 입력을 보내지 않은 것이 확인된 지점에서 기존 설정 범위로 연결을 갱신해 이어갈 수 있습니다. 같은 실행의 원래 작업 버전과 입력값을 유지합니다.

사용자 중지, 전달 여부가 불명확한 입력, 사람 확인 대기는 자동으로 넘어가지 않습니다. 편집창 시험은 현재 연결 안에서 진행하므로 긴 업무는 먼저 저장한 뒤 실행하세요.

실제 녹화 → 저장 → 재생의 최신 변경 검증은 아직 완료하지 못했습니다. 이번 실제 화면 시험은 물리적 Esc 입력으로 중지됐습니다. 실제 앱의 10,000단계 완주·장시간 무인 운영도 확인하지 않았습니다. 0.16.0에서 확인한 MuMu·Chrome·메모장·계산기·Store 결과는 이전 기록으로 구분합니다.
