COMPUTER USE MCP · 0.15.0 · 변경 안내

녹화한 동작을 검토하고,
필요한 단계만 고쳐 실행하세요

새 프로그램 등록부터 녹화·결과 확인·중단 후 재개까지 이어지는 사용 방법을 다듬었습니다.

가장 쉬운 사용 순서

  1. 앱을 평소처럼 열고 업무 시작 화면을 준비합니다.
  2. 채팅에 “지금 열린 프로그램을 등록하고 프로세스 편집창을 열어줘”라고 요청합니다.
  3. ● 동작 녹화 → 기록 시작을 누르고 실제 작업을 수행합니다.
  4. 기록 마치고 검토에서 순서·입력값을 확인하고, 보완할 단계는 이 단계만 다시 지정으로 고친 뒤 저장합니다.
  5. 시작 화면을 준비하고 저장한 작업을 실행합니다. 결과 확인 창에서는 확인 완료 또는 결과가 다름을 선택합니다.

녹화 중 사용자의 클릭·입력은 실제 프로그램에 적용됩니다. 녹화 취소는 이미 수행한 업무를 되돌리지 않습니다. 화면 동영상을 저장하는 기능은 아닙니다.

요소 인식과 동작 기록

개선한 부분사용자에게 보이는 차이
일반 버튼 기록Driver가 같은 조작 대상을 제공하면 요소 클릭으로 저장합니다. 버튼 종류만 읽혔다고 조작 가능으로 간주하지 않습니다. 정보를 연결하지 못하면 이미지 또는 보완할 단계가 됩니다.
빠른 클릭·붙여넣기마우스를 오래 올려놓지 않은 일반 Windows 컨트롤도 실제 클릭한 창·컨트롤 정보를 대조합니다. 읽을 수 있는 비보호 입력칸의 붙여넣기는 적용된 값으로 기록합니다.
겹친 화면 표시 제거다른 창이나 커서 표시 도구가 겹치면 대상 프로그램 자체의 이미지를 요청합니다. 겹친 창의 픽셀을 템플릿으로 저장하지 않으며 응답 시간·동시 요청 수를 제한합니다. 빈 이미지나 미완성 렌더링은 거절합니다.
중간값 보존같은 칸을 W → N으로 바꾼 기록은 이벤트 시점의 값과 요소 연결이 확인될 때 각 값을 따로 보존합니다. 최종 화면의 N을 앞의 W 단계에 덮어쓰지 않습니다.
요소 읽기 지연한 번의 응답 지연으로 전체 녹화의 요소 인식을 영구 중단하지 않습니다. 늦게 도착한 결과는 버리고 창별 동시 읽기를 제한하며, 응답이 돌아오면 다시 확인합니다.
녹화 전 재생 점검현재 캡처와 입력 좌표 조건을 먼저 확인합니다. 이미지 입력을 지원하지 않는 창은 요소 방식 또는 직접 보완이 필요하다고 안내합니다.
작은 녹화창녹화가 시작되면 창이 작아지고 화면을 덜 가리는 위치를 사용합니다. ‘접어두기’로 숨기고 Esc로 돌아와 일시정지할 수 있습니다.
단계 하나만 수정이미지·직접 구성할 단계를 두 번 클릭해 ‘이 단계만 다시 지정’을 사용합니다. 순서와 창 연결을 유지하며 대상·동작·입력값을 검토합니다. 보완할 단계에는 ‘이미지로 다시 지정’도 있어 이미지 선택창으로 바로 갈 수 있습니다.

자동 완료 조건이 없는 클릭은 후속 화면 확인을 유지합니다. 기록한 입력이 전달됐다는 사실을 업무 성공으로 바꾸지 않습니다. 지원되지 않는 콤보박스 선택법·불명확한 입력을 임의로 학습했다고 표시하지 않습니다.

텍스트 전용 모델에서도 기본 사용

기본 연결에서는 모델에 이미지를 자동 전달하지 않습니다. 저장된 이미지 대상은 PC 안에서 비교하고, 사람이 확인할 결과는 이 PC의 화면 확인 창에 표시합니다. 별도 모델 설정을 몰라도 녹화·저장·재생과 사람 확인을 사용할 수 있습니다.

사용자가 확인 창의 버튼을 누르면 클라이언트가 그 기록을 읽고 같은 실행을 이어갑니다. 모델이 보지 않은 이미지를 이해했다고 설명하거나 확인을 대신하지 않습니다. 확인 버튼 자체가 다음 업무 동작을 즉시 실행하지는 않습니다.

이미지 입력을 지원하는 모델로 직접 화면을 판단하려면 사용자가 이미지 전달을 요청한 뒤 시험 이미지를 확인합니다. 설정 파일 수정·재연결 없이 현재 연결의 전달 모드를 바꿀 수 있습니다. 이것이 모델에 새로운 이미지 이해 능력을 추가하거나 LLM의 API 경로를 바꾸는 기능은 아닙니다.

중단한 실행을 이어가는 방식

대상을 찾지 못하거나 준비되지 않아 아직 입력하지 않았다는 기록이 있으면 같은 실행을 이어가 현재 화면과 앞 단계의 조건을 다시 읽고 그 단계부터 진행합니다. 완료한 앞 단계의 입력을 다시 실행하지 않습니다.

방금 중단한 실행을 이어가고 싶어. 입력 전달 여부와 현재 화면을 확인하고 입력하지 못한 단계부터 같은 실행에서 진행해줘. 완료한 앞 단계는 반복하지 마.

이미 보냈거나 전달 여부가 불명확한 입력은 결과 확인부터 합니다. ‘재개’와 처음부터 ‘새로 실행’을 구분합니다. 현재 상태가 녹화 시작 화면과 다르다면 먼저 준비하고, 필요한 단계만 수정하세요.

이미지 동작·직접 화면 확인을 사용하는 작업은 기본적으로 허용 창을 앞으로 가져올 수 있습니다. 요소만 사용하는 작업은 기본 배경 실행을 사용합니다. 명시적으로 요청한 배경 실행은 유지하며 커서 움직임을 보여주는 애니메이션을 보장하지 않습니다.

새 프로그램은 채팅으로 등록

지금 열린 ‘내 업무 프로그램’을 자동화 대상으로 추가해줘. 내가 알려주는 실행 주소와 실제 업무 창을 연결해서 저장해줘.

등록 도구로 현재 창과 실행파일을 확인합니다. 주소를 여는 시작 프로그램과 업무 화면의 프로그램이 다르면 실제 업무 창을 선택합니다. 프로토콜 처리 파일을 곧바로 업무 프로그램으로 등록하지 않습니다. 연결 후 앱을 추가하는 데 설치 준비 명령이나 JSON 편집은 필요하지 않습니다.

앱 추가만으로 재접속할 필요는 없습니다. 제품 버전을 갱신할 때에는 새 파일을 사용하는 MCP로 한 번 다시 연결해야 합니다. 등록 자체는 프로그램 실행이나 모든 화면의 인식 성공을 의미하지 않습니다.

0.15.0으로 갱신하기

Driver 포함 ZIP · Driver 별도 ZIP · 릴리스 파일 전체

새 폴더에 ZIP 전체를 압축 풀고 INSTALL.md를 채팅에 첨부하세요. 필요한 Python과 도우미는 배포본에 들어 있습니다.

기존 Driver·등록한 프로그램·저장한 작업·학습 요소를 유지하고 이 버전으로 연결을 갱신해줘. MCP를 다시 연결한 뒤 computer_status의 version이 0.15.0인지 확인해줘.

이전 편집창에서 작성 중인 내용을 먼저 정리한 뒤 새 연결의 편집창을 사용하세요. 기존 파일을 받은 것과 현재 연결이 갱신된 것은 다릅니다.

지원 범위와 실제 검증은 구분합니다

  • 구형 DPI 비인식 앱은 물리/논리 좌표가 일치하고 100% 배율의 한 모니터에 들어오는 등 측정된 조건이 있어야 이미지 입력을 허용합니다. 레지스트리나 Windows 보안 설정을 바꾸지 않습니다.
  • 녹화가 끝날 때 이미 닫힌 팝업은 Driver의 동일 요소를 다시 확인하지 못할 수 있습니다. 이미지 또는 직접 보완할 단계로 남을 수 있으며 팝업의 좌표 조건도 따로 확인합니다.
  • 관련 없는 창·다른 프로세스 팝업·드래그·일부 특수 입력은 자동 기록 범위 밖일 수 있습니다. 비밀번호와 대상이 불명확한 원시 키 입력은 저장하지 않습니다.
  • 한 번에 최대 12개 동작을 기록하며 확인·대기를 포함해 최대 30단계입니다. 초안의 누락 경고와 입력값을 검토해야 합니다.
  • 로컬 이미지 검색과 녹화는 외부 LLM/API를 호출하지 않습니다. 채팅 텍스트와 선택적으로 전달하는 이미지는 연결한 클라이언트의 LLM 설정을 따릅니다.

이 문서는 변경 내용과 사용 방법입니다. 현재 시험 결과·환경·미검증 범위는 검증 보고서에서 확인하세요. 임의의 사내 프로그램·사내 LLM·무인 운영까지 검증됐다는 뜻은 아닙니다.
