0.13.0 — 등록하고 다음 화면까지 이어서

프로그램 추가는 채팅 한 번으로 요청하세요. 설정 파일을 찾거나 PowerShell 명령을 실행할 필요가 없습니다.

지금 열려 있는 ‘내 업무 프로그램’을 자동화 대상으로 등록해줘. 같은 이름이 여러 개면 목록을 보여줘. 등록만 하고 아직 실행하지 마.

경로를 알고 있다면 EXE 경로와 필요한 실행 인자를 알려주세요. 등록한 앱은 같은 연결의 다음 화면 작업부터 사용할 수 있습니다. 제품 버전 갱신은 처음 한 번 재접속해야 하지만, 새 등록 도구로 앱을 추가할 때마다 재접속할 필요는 없습니다.

버튼을 누른 뒤 창이 바뀌면 현재 결과부터 확인합니다. 관련된 새 창과 완료 조건이 확인되면 이어서 진행합니다. 이미 보낸 클릭은 반복하지 않습니다. 후보가 여러 개이거나 종료됐는지 확실하지 않으면 확인할 내용을 알려줍니다.

실행 버튼을 누르고 다음 화면의 ‘준비 완료’가 확인되면 이어서 진행해줘. 창이 바뀌어도 같은 버튼을 다시 누르지 말고 현재 결과부터 확인해줘.

커서가 움직이지 않아도 버튼에 직접 동작을 요청할 수 있습니다. 기본 배경 실행은 유지하고, 결과에 대상·입력 방식·확인 단계를 표시합니다. Driver가 실제 처리 방식을 알려주지 않으면 추측하지 않습니다. 변경 내용과 사용 예문

  2. 동봉 INSTALL.md를 채팅에 첨부하고 아래처럼 요청합니다.
  3. 연결 후 버전이 0.13.0인지 확인합니다. 이후 앱 추가는 위 예문으로 부탁하세요.
기존 Driver·등록한 프로그램·저장한 작업과 학습 요소를 유지하고 이 버전으로 연결을 갱신해줘. MCP를 다시 연결한 뒤 computer_status의 version이 0.13.0인지 확인해줘.

기다리다가 멈춘 것 같다면

동작을 보낸 뒤 결과가 확인되지 않으면 같은 버튼을 바로 다시 누르지 않습니다. 현재 창을 확인하고, 관련 창이 하나로 확인되면 결과 확인을 이어갑니다. 창이 여러 개이면 어떤 창인지 선택해야 합니다. 앱의 조회 시간과 모델의 응답 시간은 MCP 처리 시간과 따로 구분합니다.

종료 요청은 저장·종료 확인창까지 처리하고 실제 창 또는 프로세스의 종료를 확인합니다. 창이 사라졌다는 이유만으로 로그인·조회 성공을 주장하지 않습니다.

마우스가 안 움직여도 실행될 수 있습니다

Windows의 버튼·입력칸 기능에 직접 요청하는 방식은 커서를 움직이지 않아도 동작합니다. 기본 배경 실행은 이전과 같습니다. 요소 선택·녹화를 방해하던 Driver 커서 표시는 꺼져 있습니다. 창을 앞으로 가져오는 foreground는 커서 이동 애니메이션을 뜻하지 않습니다.

실행 결과에는 요청한 입력 방식과 Driver가 보고한 처리 방식을 구분해 제공합니다. 보고하지 않은 방식은 추측하지 않습니다.
