# Computer Use MCP 0.19.0

Windows 프로그램의 반복 작업을 녹화하고, 바꿀 값만 지정해 다시 실행하는 로컬 MCP입니다. **단계 → 입력값 → 스킬 보기**를 하나의 편집창에서 사용합니다.

> **배포 정보:** 이 문서는 0.19.0 기준입니다. 시험 앱의 녹화·저장·앱 재시작 후 재생·Excel 결과를 확인했습니다. 배포 파일과 실제 게시 상태는 [GitHub Releases](https://github.com/bongG-moon/computeruse_mcp/releases)에서 확인하세요.

[연결 안내](INSTALL.md) · [처음 따라 하기](PROCESS_GUIDE.html) · [변경 내용](CHANGES.html) · [검증 범위](VALIDATION.html)

## 시작하기

채팅에서 **“프로세스 편집창을 열어줘”**라고 요청하세요. 등록된 프로그램을 로컬 창에서 선택합니다. 여러 프로그램을 오가는 작업이면 함께 선택합니다.

1. **동작 녹화**를 시작하고 평소처럼 클릭·입력합니다. 녹화 중 동작은 실제 앱에 적용됩니다.
2. **단계** 탭에서 대상·값·완료 조건을 확인합니다. 필요한 단계만 고치거나 녹화를 추가·교체할 수 있습니다. 되돌리기는 편집 내용만 취소하며 실제 앱 입력을 되돌리지 않습니다.
3. **입력값** 탭에서 실행마다 바꿀 값의 이름·형식·필수 여부·기본값과 사용 단계를 관리합니다.
4. **시험 실행**에서 로컬 입력창에 값을 넣고 결과를 확인한 뒤 저장합니다. 저장 후에도 창을 닫지 않고 계속 편집할 수 있습니다.
5. **스킬 보기 → 미리보기 갱신 → 보이는 내용 내보내기**로 저장본 호출 안내를 만듭니다. 개인 스킬에 자동 설치하지 않습니다.

다음부터 **“저장한 작업을 실행해줘”**라고 요청하면 실제 입력값은 이 PC의 입력창에서 받습니다. 중단한 작업은 **“같은 실행을 이어가줘”**라고 요청하세요. 처음 시작한 버전과 입력값을 유지하며 이미 보냈거나 전달이 불명확한 입력은 반복하지 않습니다.

## 값과 동작을 분리하기

입력값은 텍스트·날짜·선택값·숫자·정수·참/거짓·목록 형식을 지원합니다. 같은 값이 쓰이는 단계도 함께 확인할 수 있습니다. 특정 항목을 이미지로 클릭한 동작은 문자열만 바꿔 다른 항목을 누르게 할 수 없으며, 대상 변경은 편집창에서 지정합니다.

작업을 수정하면 새 revision으로 저장합니다. 기존 녹화·재생 이미지·이전 버전은 자동 변환하지 않습니다. 미완성 기록은 초안으로 남기고 필요한 단계만 보완합니다. 녹화 경고를 확인했다고 누락된 입력이 복원되는 것은 아닙니다.

스킬에는 불투명한 작업 ID와 고정 revision의 호출만 들어갑니다. 업무명·입력 기본값·화면·내부 경로를 넣지 않습니다. 미리 본 파일과 내보낸 파일은 동일하며, 편집을 바꾸면 저장과 미리보기를 다시 해야 합니다. 파일만 다른 PC로 옮겨도 원래 저장 작업이 함께 옮겨지는 것은 아닙니다.

## 데이터가 머무는 곳

기본 `data_policy=local`에서는 업무 화면·입력값·상세 오류·스킬 본문을 로컬 창에서 확인합니다. 채팅에는 불투명한 ID, 상태와 진행 개수만 반환합니다. 작성 기능에 외부 모델 API·원격 OCR·자동 업로드를 추가하지 않았습니다.

기존 작업이 모델 화면 판정(`visual/deferred_visual`)에 의존하면 로컬 모드에서 **첫 입력 전에 중지**합니다. 편집창에서 자동 완료 조건 또는 직접 확인으로 새 revision을 저장하세요. 사람 확인을 자동 승인하거나 기존 실행 기록을 바꾸지 않습니다.

관리자가 명시한 `data_policy=connected`는 기존 사내 클라이언트의 화면 관찰·말로 직접 조작·모델 판정 경로를 유지합니다. 이 모드는 로컬 전용 보장이 적용되지 않습니다. 사용자 채팅, 다른 파일 도구, 업무 앱 자체의 통신까지 이 MCP가 차단하는 것은 아니므로 사외 통신 제한은 클라이언트·모델·네트워크 정책에서도 보장해야 합니다.

## 기존 기능과 실행속도

기존 창·팝업 연결, UIA/MSAA·이미지 비교, 입력 전달·결과 확인, 동일 실행 재개 엔진을 유지합니다. 새 편집 분석이나 스킬 생성은 재생 단계마다 반복하지 않습니다. 동작마다 불필요한 모델 확인을 더하지 않으며 고정 대기를 늘리지 않습니다.

가상 화면을 쓰는 재생 엔진 비교 120회에서 입력·관찰 횟수는 같았습니다. 중앙값 증가는 최초 실행 2.73%, 반복 실행 0.45%로 5% 회귀 경보선 미만이었습니다. 실제 Driver·운영 앱·모델의 지연을 측정한 결과나 업무 10초 완료 보장은 아닙니다. [상세 검증 범위](VALIDATION.html)를 확인하세요.

## 연결·등록·보관

배포 ZIP 전체를 새 폴더에 풀고 [INSTALL.md](INSTALL.md)를 채팅에 첨부하세요. 기존 프로그램 설정과 저장 작업을 유지해 연결을 갱신합니다. Python을 별도로 설치하거나 앱마다 인식 엔진을 선택할 필요는 없습니다. 파일 교체 후에는 MCP 연결을 다시 시작해야 새 코드가 적용됩니다.

메모장·계산기·Chrome·Microsoft Store와 사용자 지정 EXE·실행 주소를 등록할 수 있습니다. ClickOnce `.appref-ms`는 [별도 안내](APPREF_GUIDE.md)를 참고하세요. 등록된 앱만 조작하며 인식 범위는 앱·컨트롤마다 다릅니다.

캡처와 임시파일은 기록 폴더의 실행별 하위 폴더에 모입니다. 사용이 끝난 임시파일은 도우미 종료를 확인한 뒤 정리합니다. 완성 작업에 반영된 복구용 녹화 원본은 저장 후 7일이 지나면 정리할 수 있지만, **재생에 필요한 기준 이미지·저장 작업·이전 버전·실제 Excel/PPT 결과물은 보존**합니다. 초안·저장 실패 원본과 소유를 확인하지 못한 파일도 보존합니다.

입력 전송은 업무 성공과 다릅니다. 정한 완료 조건을 읽어서 확인하며, 종료를 요청한 경우 실제 창 종료와 남은 저장 대화상자를 구분합니다.
