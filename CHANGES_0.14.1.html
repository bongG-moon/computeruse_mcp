COMPUTER USE MCP · 0.14.1

요소 선택의 이유를 설명하고
최대화된 창도 캡처합니다

프로세스 편집창의 요소 선택·이미지 캡처 오류를 수정했습니다.

“버튼”인데 왜 이미지로 넘어가나요?

Windows가 커서 아래 대상을 버튼이라고 알려주어도, 자동 조작 도구가 같은 버튼을 조작 대상으로 제공하지 않을 수 있습니다. 이런 화면은 이미지를 직접 선택해 저장할 수 있습니다.

이제 “버튼 정보가 없다”는 일괄 안내 대신 조작 목록에 없음·식별 정보 부족·위치 불일치·빈 읽기 결과를 구분합니다. 선택을 다시 하라는 안내만 반복할 필요 없이 채팅에서 마지막 원인도 확인할 수 있습니다. 다른 부모 요소를 임의로 대신 선택하지 않습니다.

캡처가 되지 않던 부분을 수정했습니다

  • 최대화된 창: 화면 밖으로 조금 나가는 보이지 않는 테두리를 캡처 영역에서 제외합니다.
  • 최소화된 창: ‘대상 창을 가져와 캡처’를 누르면 해당 창을 복원하고 전환 상태를 최대 2초간 확인합니다.
  • 재캡처 실패: 이전 이미지와 선택을 지워 오래된 이미지가 잘못 저장되지 않도록 합니다.
  • 이유별 안내: 다른 창에 가려짐, 창 닫힘, 화면 밖, 활성화 실패, 큰 창 등을 구분하고 오류 코드를 함께 표시합니다.

캡처 버튼은 대상 창을 복원하고 앞으로 가져옵니다. 업무 프로그램의 버튼을 누르거나 글자를 입력하지 않습니다. 화면의 가려진 부분이나 실제로 모니터 밖에 있는 내용은 임의로 캡처하지 않습니다.

사용 순서

  1. 프로세스 편집창에서 요소 직접 선택으로 대상을 고릅니다.
  2. 이미지 선택으로 이어지면 대상 창을 가져와 캡처를 누릅니다.
  3. 표시된 이미지에서 버튼과 주변 이름을 함께 드래그합니다.
  4. 오른쪽 미리보기에서 실제 누를 위치를 찍고 이 이미지로 선택을 누릅니다.
  5. 동작을 추가한 뒤 프로세스를 저장합니다.

같은 아이콘이 여러 줄이면 해당 줄의 이름까지 포함하세요. 캡처가 실패하면 새 안내의 원인과 코드를 채팅으로 전달하면 됩니다.

새 버전 적용

0.14.1 배포 파일을 새 폴더에 압축 해제한 뒤 INSTALL.md를 채팅에 첨부하고 아래처럼 요청하세요.

기존 Driver·등록한 프로그램·저장한 작업·학습 요소를 유지하고 이 버전으로 갱신해줘. MCP를 다시 연결한 뒤 computer_status의 version이 0.14.1인지 확인하고 프로세스 편집창을 새로 열어줘.

기존 편집창을 계속 사용하면 이전 도우미가 남아 있을 수 있습니다. 저장할 내용을 먼저 정리한 뒤 새 연결에서 편집창을 여세요.

검증 범위

화면 경계 계산은 실제 C# 코드로 최대화·음수 좌표·모니터 경계와 빈 공간·크기 제한을 검사합니다. 요소 선택 진단과 이미지 매칭·프로세스 회귀검사도 수행합니다. 실제 창 검증 여부는 검증 결과에 별도로 표시합니다.

이 변경이 모든 사내 프로그램의 요소 인식을 보장하지는 않습니다. 캡처 한 변은 최대 4096픽셀이며, 이를 넘으면 창을 줄여서 선택합니다. 여러 모니터의 계산 검사와 실제 여러 모니터 시험은 구분합니다.
