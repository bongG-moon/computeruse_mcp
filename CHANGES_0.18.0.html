이미지 녹화의 제한시간 오류 보완

녹화할 이미지를 구별하는 처리에서 발생한 제한시간 오류를 보완했습니다. 마지막 수정 뒤 Chrome에서 드롭다운을 열고 항목을 고른 실제 클릭 2/2개의 이미지가 보존됐습니다. 제한시간 오류·수동 보완·미해결 단계는 각각 0개였으며 기존 녹화 원본은 바뀌지 않았습니다.

대상 밖 동작 경고는 유지됩니다. 이 확인에서는 작업을 새로 저장하거나 재생하지 않았고, 전체 자동 검사도 다시 실행하지 않았습니다. 관련 자동 검사 6개는 통과했으며 합성 큰 화면의 처리시간은 309ms였습니다. 실제 Chrome 이미지별 처리시간은 측정하지 않았으므로 이 수치를 실제 녹화 속도로 해석하지 않습니다. 확인한 범위와 남은 경고

녹화

  • 녹화 창으로 돌아오는 것만으로 ‘다른 프로그램 동작 누락’ 경고를 만들지 않습니다.
  • 글자를 입력한 직후 녹화를 마쳐도 마지막 입력칸의 값을 짧게 확인합니다. 확인할 수 없는 내용은 성공으로 처리하지 않습니다.
  • 등록한 다른 창을 처음 클릭할 때도 동작을 버리지 않습니다. 클릭 전 이미지를 확보하지 못한 경우에는 수정 가능한 단계로 보존합니다.

Canvas 입력은 해당 단계에서 한 번만 보완

요소 정보로 값을 읽을 수 없는 그림 형태의 입력칸에서는 키보드로 친 글자를 자동 수집하지 않습니다. 직전 클릭의 이미지를 확인할 수 있으면 입력 위치 후보 · 값 확인 필요로 표시합니다. 단계를 두 번 클릭해 이미지를 보고 원하는 값을 한 번 지정하면 됩니다. 위치가 틀리면 같은 창의 다른 위치 선택으로 해당 단계만 고칩니다. 전체 녹화를 다시 할 필요는 없습니다.

후보는 입력칸으로 검증된 요소가 아닙니다. 사용자가 위치와 값을 지정하기 전에는 실행하지 않으며, 지정할 때도 앱에 입력하지 않습니다. 이미지가 없거나 표시할 수 없으면 후보를 승인해 실행하지 않고, 대상을 다시 지정할 수 있는 초안으로 남깁니다. 재생 시 기존 내용을 전체 바꾸므로 빈 값은 기존 내용 삭제를 뜻합니다.

화면 겹침 안내도 대상 이미지를 확정하지 못한 상태로 설명합니다. 사용자가 다른 창으로 가렸다고 단정하지 않습니다. 이미지가 있을 때와 없을 때의 보완 방법

마지막 제한시간 수정 전에는 Windows Canvas 14/14단계와 Chrome Canvas 16/16단계 재생을 확인했습니다. 사용자의 입력 위치·값 보완과 모델의 화면 판단이 포함된 결과이며, 무인 재생 성공을 뜻하지 않습니다. 마지막 수정 뒤 같은 전체 재생을 다시 수행하지 않았습니다. Canvas 시험 결과와 보완 범위

이미지 탐색

기존 이미지 비교를 먼저 사용하고, 대상을 찾지 못했을 때만 Airtest가 보조로 검색합니다. 실제 실행 시간을 비교해 정한 순서이며 사용자가 엔진을 선택할 필요는 없습니다. 중복 후보나 구분 정보 부족은 다른 엔진으로 우회하지 않습니다.

Airtest는 제한 시간이 있는 별도 프로세스에서 로컬 이미지를 비교합니다. 이미지 라이브러리 초기화가 지연되어도 MCP 전체가 멈추지 않도록 했습니다. 별도 모델 API나 실행 중 다운로드를 사용하지 않습니다.

문서 입력과 Windows 앱

메모장처럼 편집 영역이 ‘문서’로 표시되는 프로그램도 최종 입력값을 기록합니다. 문서 내용이 바뀌어도 현재 창의 고유한 편집 영역을 다시 찾으며, 읽기 전용 문서는 입력 대상으로 저장하지 않습니다.

계산기처럼 바깥 프레임과 실제 앱 창이 분리된 경우에도 연결된 내부 창을 확인해 녹화와 결과 확인을 진행합니다. 검은 화면이 반환되는 캡처 경로도 보완했습니다.

화면 배율 때문에 이미지 클릭 좌표를 확인할 수 없어도, 요소 정보를 읽을 수 있으면 요소 방식으로 녹화합니다. Windows 배율이나 설정 파일을 바꿀 필요는 없습니다. 이 경우 이미지 동작은 만들지 않으며 인식되지 않은 부분은 보완할 단계로 남깁니다.

녹화 도구로 돌아왔을 때는 기록이 보존된다는 안내를 표시합니다. 녹화 준비 실패 시 창 활성화 문제와 캡처 문제를 구분해 안내합니다. 앱별 실제 검증 결과

응용 프로그램 참조로 실행

.appref-ms 파일로 여는 ClickOnce 앱도 채팅으로 추가할 수 있습니다. 참조 파일 경로를 알려주고 실제 업무 창을 한 번 선택하세요. 실행 방법과 조작 대상은 따로 기억하므로 사용자가 설정 파일을 편집하지 않아도 됩니다. 프로그램 추가 안내

저장한 작업 수정과 스킬

입력값이나 체크 상태만 바꾸면 같은 대상에 연결된 기존 값 확인 조건도 함께 갱신합니다. 사용자가 별도로 정한 조건이나 다른 요소의 확인 조건은 유지합니다. 클릭 대상을 바꿀 때는 새 동작에 맞는 완료 기준을 함께 확인하세요.

스킬에는 작업 이름, 사용할 저장 버전, 입력값과 정확한 호출 방법이 들어갑니다. 내보낸 파일을 채팅에서 읽게 한 뒤 조건이나 검색어 목록만 바꿔 요청할 수 있습니다. 개인 스킬 설정을 자동 변경하지 않으며, 다른 PC에서 쓰려면 참조하는 작업과 프로그램도 준비되어 있어야 합니다.

조회 결과의 변화를 이미 확인했는데도 이어가기에서 같은 변화를 다시 요구하며 멈추던 문제를 수정했습니다. 원래 실행의 확인 기록과 실제 프로그램·창이 일치할 때 현재 결과를 다시 읽습니다. 기록이 없거나 입력 여부가 불확실하면 완료로 바꾸거나 입력을 반복하지 않습니다.

반복 실행의 결과 확인

표 셀을 빠른 확인 방식에서 다른 종류로 표시해 찾지 못하는 경우, 같은 클릭을 반복하지 않고 일반 Driver 읽기로 전환합니다. 전환 후에는 같은 동작에서 실패한 빠른 읽기를 되풀이하지 않습니다. 다른 창이나 모호한 요소를 읽은 결과, 시간이 지난 응답은 성공으로 인정하지 않습니다.

Windows 요소 인식

FlaUI UIA2/UIA3를 실제 프로그램과 비교했지만 이번 시험에서는 더 많은 고유 요소를 찾지 못했습니다. 현재 요소 인식은 유지하고, FlaUI 비교 도구는 개발용으로만 보관합니다.

조건 입력칸이 많고 같은 이름의 버튼이 여러 곳에 있는 화면에서, 일부 중간 영역이 생략됐다는 이유로 전체 화면 읽기가 멈추던 문제를 수정했습니다. 라벨과 주변 영역의 문맥도 함께 전달해 어느 조건과 버튼인지 판단하는 데 활용합니다. 편집창에는 Family·Device처럼 구분에 필요한 글자를 먼저 보여 주고 해당 영역을 덧붙입니다. ‘주변 글자 기준’ 표시로 추론한 의미와 프로그램이 직접 제공한 요소 이름을 구분합니다.

같은 콤보박스에서 드롭다운을 열고 항목을 고른 실제 동작은 하나의 선택값 변경으로 기록합니다. 다른 드롭다운이나 중간에 다른 입력이 있었던 동작을 임의로 합치지 않습니다. 14개 조건을 가진 Windows 시험 앱에서 서로 다른 두 녹화를 수동 보완 없이 저장하고, 각각 초기화 후 6/6단계 재생을 완료했습니다. 세 입력값·체크 상태·결과 5행과 조회 1회 실행을 독립 기록으로 확인했습니다. 최초 녹화의 미해결 단계도 숨기지 않고 검증 기록에 남겼습니다. 확인된 결과와 남은 시험
