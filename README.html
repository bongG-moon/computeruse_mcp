COMPUTER USE MCP / 0.16.0 검증 결과

화면 작업을 부탁하거나,
한 번 보여주세요.

실제 앱 조작과 저장 작업 재생 검증을 완료했습니다.

MuMu 첫 번째 줄의 실행 버튼을 한 번 누른 뒤 로딩·녹색 실행 상태를 확인했고, 메모장은 입력 문구 일치와 창 종료를 확인했습니다. MuMu의 Android 내부 준비 완료는 확인하지 않았습니다.

Chrome의 입력·상태 선택·조회 결과와 종료, 계산기의 2 + 3 = 5와 종료, Store의 앱 항목 선택과 종료를 확인했습니다. Store는 종료를 재입력하지 않고 읽기 전용으로 다시 확인했습니다. 설치·구매·로그인은 시험하지 않았습니다.

시험 앱의 실제 동작 3개를 5단계로 기록·저장하고, 중단 지점 재개와 처음부터 새로 실행하는 시험을 모두 완료했습니다. MuMu의 원래 녹화는 사용자가 한 단계의 대상을 다시 지정한 뒤 저장했습니다. 이후 중단 지점 이어가기와 처음부터 새로 실행하기를 각각 4/4단계 완료했습니다. 버튼 색상 차이는 모델이 현재 화면으로 복구했고 추가 지정이나 저장 원본 변경 없이 진행했습니다. 이어가기에서 완료한 첫 클릭은 반복하지 않았습니다. 각 실행의 화면 확인 2개는 모델 판단입니다. 최신 캡처 변경은 자동 검사·시험 앱에서 확인했으며 MuMu 전체를 다시 녹화한 시험은 아닙니다. 전체 검사 1,327개 중 1,325개 통과·2개 조건부 제외(69.477초), 독립 검사 191개 모두 통과했습니다.

채팅으로 바로 조작하는 방식과, 직접 녹화해서 반복하는 방식.
두 가지 시작점에서 같은 화면 조작 엔진을 사용합니다.

01 / 말로 실행

원하는 작업을 알려주세요

계산기를 열고 12 + 30을 계산한 뒤 결과를 확인해줘.

현재 프로그램 창을 연결하고 요소를 찾습니다. 이미지 모델을 연결한 경우 그림으로 표시되는 화면도 관찰해 조작할 수 있습니다.

02 / 직접 가르치기

프로세스 편집창에서 녹화하세요

지금 열린 프로그램에서 반복할 작업을 녹화하게 편집창을 열어줘.

녹화 → 단계 검토 → 시험 실행 → 저장. 대상을 다시 고를 때도 ‘화면에서 선택’ 한 곳에서 처리합니다.

다음에는 값만 바꿔 실행하세요

저장한 조회 작업을 검색어 N으로 실행해줘.

입력 변수, 단계 수정, 이전 버전 조회와 복원을 지원합니다. 중간에 멈춘 작업은 원래 버전과 입력값으로 이어가며, 이미 전달했을 수 있는 입력을 무작정 반복하지 않습니다.

직접 대상을 수정하면 해결된 대상 경고도 정리됩니다. 버튼 색상이 달라 재생이 입력 전에 멈추면, 이미지 모델이 저장된 대상과 현재 화면을 비교해 이번 실행에서만 같은 대상을 다시 찾을 수 있습니다. 저장된 작업은 유지하고 이미 수행한 입력을 반복하지 않습니다.

알아두면 좋은 점
  • 녹화 중 클릭·입력은 실제 프로그램에 적용됩니다.
  • 메모장·계산기·Chrome·Store와 사용자 지정 프로그램을 등록할 수 있습니다. 프로그램별 인식과 실행 가능 범위는 다릅니다.
  • 화면을 해석하는 AI는 연결한 앱의 모델입니다. 이 MCP 자체는 외부 모델 API를 호출하지 않습니다. 이미지 전달은 이미지 모델 연결에서 명시적으로 켭니다.
  • 클릭 전달, 실제 값 확인, 모델의 화면 판단을 구분합니다. 저장·종료 대화상자가 남아 있으면 완료로 보고하지 않습니다.
