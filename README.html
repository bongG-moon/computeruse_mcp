화면 작업을 부탁하거나,
한 번 보여주세요.

이미지 선택, 녹화·초안 저장과 긴 반복 작업을 개선했습니다.

누를 곳을 한 번 클릭하면 주변 이름·그림을 함께 확인합니다. 대상이 가려진 경우와 주변 영역 일부만 가려진 경우를 구분하고, 관련 팝업의 기록을 보완했습니다. 빠진 단계가 있어도 초안으로 저장해 나중에 이어서 수정할 수 있습니다.

작성 1,000단계 · 반복 목록 1,000개 · 반복을 포함한 실행 10,000단계 · 한 번 녹화 300동작. 반복할 동작은 한 번만 저장하며, 긴 저장 작업은 완료 지점을 보관해 같은 실행으로 이어갑니다. 이미지 용량 한도는 별도로 유지합니다.

자동 검사 1,387개 중 최종 1,382개 통과·5개 제외·미해결 실패 0개입니다. 시험용 모형 보정 후 관련 재검사를 포함합니다. 이번 실제 화면 시험은 Esc 중지로 녹화부터 재생까지 완료하지 못했습니다. 이전 실제 앱 결과는 0.16.0 기록과 구분합니다.

채팅으로 바로 조작하는 방식과, 직접 녹화해서 반복하는 방식.
두 가지 시작점에서 같은 화면 조작 엔진을 사용합니다.

01 / 말로 실행

원하는 작업을 알려주세요

계산기를 열고 12 + 30을 계산한 뒤 결과를 확인해줘.

현재 프로그램 창을 연결하고 요소를 찾습니다. 이미지 모델을 연결한 경우 그림으로 표시되는 화면도 관찰해 조작할 수 있습니다.

02 / 직접 가르치기

프로세스 편집창에서 녹화하세요

지금 열린 프로그램에서 반복할 작업을 녹화하게 편집창을 열어줘.

녹화 → 단계 검토 → 시험 실행 → 저장. 미완성 상태는 초안으로 저장할 수 있습니다. 대상을 다시 고를 때도 ‘화면에서 선택’ 한 곳에서 처리합니다.

다음에는 값만 바꿔 실행하세요

저장한 조회 작업을 검색어 N으로 실행해줘.

입력 변수, 단계 수정, 이전 버전 조회와 복원을 지원합니다. 중간에 멈춘 작업은 원래 버전과 입력값으로 이어가며, 이미 전달했을 수 있는 입력을 무작정 반복하지 않습니다.

직접 대상을 수정하면 해결된 대상 경고도 정리됩니다. 버튼 색상이 달라 재생이 입력 전에 멈추면, 이미지 모델이 저장된 대상과 현재 화면을 비교해 이번 실행에서만 같은 대상을 다시 찾을 수 있습니다. 저장된 작업은 유지하고 이미 수행한 입력을 반복하지 않습니다.

알아두면 좋은 점
  • 녹화 중 클릭·입력은 실제 프로그램에 적용됩니다.
  • 메모장·계산기·Chrome·Store와 사용자 지정 프로그램을 등록할 수 있습니다. 프로그램별 인식과 실행 가능 범위는 다릅니다.
  • 화면을 해석하는 AI는 연결한 앱의 모델입니다. 이 MCP 자체는 외부 모델 API를 호출하지 않습니다. 이미지 전달은 이미지 모델 연결에서 명시적으로 켭니다.
  • 클릭 전달, 실제 값 확인, 모델의 화면 판단을 구분합니다. 저장·종료 대화상자가 남아 있으면 완료로 보고하지 않습니다.
