연결 안내 · 처음 따라 하기 · 실제 검증 범위
0.19.1은 로컬 설치 진단과 저장 직후 시험 실행의 팝업 연결 오류를 수정합니다. 새 검증과 0.19.0의 과거 시험 결과는 검증 범위에서 구분합니다. 배포 파일과 실제 게시 상태는 GitHub Releases에서 확인하세요.

0.19.1에서 고친 두 가지

  • 설치 진단: 로컬 모드에서 실제로 있는 기본 도구를 누락으로 판단하던 오류를 수정했습니다. 기존 설정과 data_policy=local을 유지해 연결을 갱신하세요.
  • 저장 직후 시험 실행: 녹화 때 열었던 팝업이 닫혔어도 시작 단계에서 오류로 중지하지 않고, 팝업을 여는 단계에서 다시 찾습니다. 기본 업무 창이 닫혔다면 입력 전에 다시 연결하도록 안내합니다.

기존 녹화·저장 작업·실행 기록은 유지합니다. 이 오류 수정 때문에 전체 작업을 다시 녹화할 필요는 없습니다.

설정 파일 대신 편집창에서 시작하세요

프로세스 편집창을 열어줘.
  1. 단계: 직접 작업을 녹화하고 대상·값·완료 조건을 확인합니다. 필요한 구간만 추가·교체하거나 편집을 되돌릴 수 있습니다.
  2. 입력값: 실행마다 바꿀 값의 형식·기본값·필수 여부와 사용 단계를 관리합니다. 실행 값은 이 PC의 입력창에서 받습니다.
  3. 스킬 보기: 저장한 작업을 호출하는 안내 전체를 미리 보고 그대로 내보냅니다. 자동 설치하지 않습니다.

녹화 중 클릭·입력은 실제 프로그램에 적용됩니다. 편집 되돌리기가 실제 앱 입력을 취소하지는 않습니다.

기존 기록은 유지합니다

기존 녹화·재생 이미지·이전 revision을 자동 변환하지 않습니다. 수정은 새 revision에 저장하고, 진행 중 실행은 처음 시작한 버전과 입력값으로 이어갑니다. 이미 보냈거나 전달 여부가 불명확한 클릭을 다시 누르지 않습니다.

이미지로 특정 항목을 클릭한 단계는 텍스트 값만 바꿔 다른 항목을 누르게 할 수 없습니다. 해당 대상은 편집창에서 지정하세요. 누락 경고가 남은 기록은 초안으로 보존하고 필요한 단계만 고칩니다.

상세 내용은 이 PC에서 확인합니다

기본 로컬 정책에서는 업무 화면·입력값·상세 오류를 채팅에 반환하지 않습니다. 설치 진단에는 도구 구성·고정된 도우미 파일명·존재 여부·버전만 추가로 전달합니다. 작성 기능은 외부 모델 API·원격 OCR·자동 업로드를 사용하지 않습니다. 스킬에도 업무 값·이미지·내부 경로를 담지 않습니다.

기존 작업이 모델의 화면 판정에 의존하면 첫 입력 전에 중지합니다. 편집창에서 자동 완료 조건 또는 직접 확인으로 새 revision을 저장하세요. 관리자가 명시한 connected 모드에서는 기존 사내 클라이언트의 말로 조작·모델 판정 경로를 사용할 수 있으며 로컬 전용 보장은 적용되지 않습니다.

사용자 채팅·다른 파일 도구·업무 앱의 통신까지 이 MCP가 차단하지는 않습니다. 사외 통신 제한은 클라이언트·모델·네트워크 정책에서도 보장해야 합니다.

반복 실행에 편집 작업을 더하지 않습니다

재생 엔진은 유지하고 편집 분석·스킬 생성은 작성할 때만 수행합니다. 입력·관찰 횟수를 늘리거나 확인을 자동 성공 처리하지 않습니다. 0.19.0 당시 가상 화면 기반 120회 비교에서는 최초 실행 중앙값 +2.73%, 반복 실행 +0.45%였으며 실제 운영 앱 지연은 별도 검증 대상입니다.

변경 내용 · 시험 결과와 한계 · ClickOnce 프로그램 연결

특정 시험 화면의 성공이 모든 앱·테마·배율의 성공을 보장하지 않습니다.
