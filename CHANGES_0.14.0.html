0.14.0 — 화면을 읽고, 진행 상황을 알려주며 이어서 실행합니다

복잡한 화면을 반복해서 전부 읽는 일을 줄이고, 무엇을 기다리는지 확인할 수 있게 했습니다. 새로운 프로그램에도 같은 방식을 사용합니다.

개선사용 방법
화면 정보가 부족할 때같은 창의 이미지를 함께 확인합니다. 세션을 다시 시작할 필요가 없고, 클릭 권한이 자동으로 늘어나지도 않습니다. 캡처할 창은 맨 앞에 표시되어 있어야 하며 자동으로 창을 전환하지 않습니다.
오래 걸릴 때단계 번호와 화면 읽기·입력·결과 확인 상태를 보냅니다. “지금 무엇을 기다리는지 알려줘”로 실행 중 상태를 별도로 조회할 수 있습니다.
복잡한 화면의 일부만 확인고유한 부모를 찾는 식별 정보는 전체 창에서 확인하고, 값·동작 속성은 선택한 하위 영역에서만 읽습니다. 모든 앱에서 같은 속도가 나오지는 않습니다.
이미지 클릭 후 자동 진행편집 창에서 완료를 확인할 요소와 예상 값을 선택하세요. 실행 전후의 변화까지 새로 확인되면 이어갑니다. 조건을 읽을 수 없거나 달라지지 않으면 멈추고, 클릭을 반복하지 않습니다.
팝업을 포함한 동작 녹화원래 창이 연 같은 프로세스의 팝업을 함께 기록합니다. 재실행 때 현재 팝업을 다시 찾아 연결합니다. 관계가 불명확한 창은 자동으로 포함하지 않습니다.
이미지가 이 채팅에 제대로 전달되는지 먼저 확인해줘. 그다음 현재 프로그램으로 프로세스 편집 창을 열어줘. 이미지로 클릭한 뒤에는 내가 지정한 완료 요소의 값이 바뀌었는지 확인하고 이어서 실행하도록 만들고 싶어.

처음 한 번: computer_check_image는 화면 대신 시험 이미지를 보내, 그 안의 코드를 읽어 돌려받습니다. 시험 이미지 전달 성공과 실제 업무 화면을 이해하는 정확도는 별개입니다. 사내 LLM을 이 PC에서 검증한 것은 아닙니다.

자동 완료 확인을 지정하지 않은 이미지 단계와 기존 화면 확인 단계는 사람이 확인한 뒤 이어갑니다. 동작 녹화는 동영상 저장이 아니라 클릭·지원되는 입력과 상태를 순서대로 기록하는 기능입니다. 학습·녹화 사용 안내

같은 드롭다운을 여러 번 열어도 각각의 순서로 기록합니다. 이미지 클릭으로 팝업이 열리면 그 팝업을 찾아 화면 확인을 이어갑니다. 이미지를 확보하지 못한 녹화 항목은 저장 전에 직접 보완하도록 표시합니다.

새 버전 적용은 한 번만

  1. 0.14.0 릴리스의 Driver 포함 ZIP을 새 폴더에 모두 압축 풉니다.
  2. 동봉 INSTALL.md를 채팅에 첨부하고 아래 문장을 요청합니다.
  3. MCP를 다시 연결한 뒤 버전 0.14.0을 확인합니다.
기존 Driver·등록한 프로그램·저장한 작업·학습 요소를 유지하고 이 버전으로 갱신해줘. 다시 연결한 computer_status의 version이 0.14.0인지 확인해줘.

기다리는 이유를 확인하세요

지금 몇 번째 단계이고 무엇을 기다리는지 알려줘.

현재 단계, 경과 시간과 대기 상태를 조회합니다. 클라이언트가 실시간 알림을 표시하면 자동으로 보이며, 그렇지 않아도 진행 조회 도구로 확인할 수 있습니다. 프로그램 서버의 조회 시간이나 모델 응답 시간 자체를 없애지는 못합니다.

확인 범위

Windows 합성 시험 창과 실제 Driver/MCP로 검증합니다. 사내 프로그램·사내 LLM은 연결하지 않았습니다. 이미지 인식·녹화·빠른 범위 조회가 모든 프로그램에서 같은 결과나 속도를 보장하지는 않습니다. 상세 측정과 제외 항목은 검증 기록에서 확인하세요.
