# Agent Desktop Local 0.1.1

기존 CUA와 나란히 사용할 수 있는 읽기 전용 Windows 인식 스킬입니다. agent-desktop 1.1.0을 고정하고 메뉴, 콤보, 표, 속성 편집기의 부모/팝업 범위를 따로 관찰합니다. 기존 Computer Use MCP 0.19.5를 교체하지 않습니다.

**처음 사용한다면 압축을 푼 폴더의 [사용가이드.html](사용가이드.html)을 더블클릭하세요.** 준비할 파일, 사내 에이전트에 요청하는 방법, 수동 테스트, 결과 확인과 문제 해결을 순서대로 안내합니다. 인터넷 연결 없이 열 수 있습니다.

## 어떤 릴리스를 받아야 하나요?

이 스킬은 `agent-desktop-local-v0.1.1`이라는 별도 릴리스입니다. 기존 CUA 최신 `v0.19.5` ZIP에는 들어 있지 않습니다. `Agent-Desktop-Local-0.1.1-windows-x64.zip`을 별도로 받아 사용하세요. 이 ZIP에는 사용 가이드와 실행 엔진이 함께 들어 있습니다. 기존 파일을 덮어쓰지 않고 새 폴더에 풉니다.

| 구성 요소 | 필요 여부 |
|---|---|
| CUA Driver (`cua-driver.exe`) | 필요 없음 |
| `agent-desktop.exe` | 필요함. Windows용 ZIP의 `bin` 폴더에 이미 포함 |
| Python 3.10 이상 | 필요함. 이 ZIP에는 포함하지 않음. 회사에서 승인한 기존 런타임 사용 |
| JEV, npm, API 키, 외부 모델 | 필요 없음 |
| 관리자 권한 설치, Windows 서비스, 커널 드라이버 | 이 스킬이 설치하지 않음 |

CUA Driver 없이 동작한다는 뜻이지 실행 엔진이 없다는 뜻은 아닙니다. 포함된 `agent-desktop.exe`가 Windows 접근성 정보를 읽습니다. 모델이 직접 사용하려면 로컬 파일과 명령 실행 도구가 있는 사내 에이전트가 필요합니다. 채팅 전용 모델만으로는 PC를 읽을 수 없습니다.

## 준비

Windows 10 1809 이상 x64와 Python 3.10 이상이 필요합니다. CUA나 JEV, API 키, 외부 모델은 필요하지 않습니다. Python 설치와 보안 정책 변경은 자동으로 하지 않습니다. Python이 없다면 회사에서 허용한 기존 런타임을 사용합니다.

릴리스의 `Agent-Desktop-Local-0.1.1-windows-x64.zip`을 동기화되지 않는 로컬 폴더에 풉니다. `agent-desktop-local/SKILL.md`를 승인된 사내 에이전트에 등록하거나 읽게 합니다. 프로젝트 전용 또는 사용자 계정 전용 스킬 위치 중 필요한 범위를 직접 선택해 복사합니다. 기존 CUA 스킬 폴더를 덮어쓰지 않습니다. 자동 설치기와 상시 실행 서비스는 없습니다.

회사 앱을 직접 열고 스킬에 정확한 실행파일 이름을 알려 주세요. 예시 요청: “APP.exe의 현재 메뉴와 콤보, 표를 읽기 전용으로 확인해 줘. 결과는 C:\LocalReview에 보관해 줘.” 실제 명령과 자료 경계는 [SKILL.md](SKILL.md)에 있습니다. `python`이 경로에 없으면 명령의 첫 부분을 승인된 `python.exe`의 전체 경로로 바꿉니다.

## 외부 전송 범위

래퍼는 네트워크 클라이언트와 외부 서비스 연동을 포함하지 않습니다. JEV, npm 설치 스크립트, 업데이트 확인, 원격 로그 전송은 배포하지 않습니다. 실행 응답에는 상태/개수/임의 영수증만 출력하며 업무 텍스트는 로컬 파일에 남습니다. 사내 모델에서 해당 파일을 읽어 해석할 수 있습니다. 원시 결과 폴더를 외부 모델이나 이슈에 첨부하지 마세요.

이는 OS 네트워크 차단이나 악성 사용자 방어용 샌드박스가 아닙니다. 원본 agent-desktop.exe 자체에는 다른 자동화 명령도 있습니다. 이 스킬은 해시를 확인하는 관찰 래퍼만 사용합니다. 결과 폴더의 클라우드 동기화나 호스트 모델의 전송 정책은 별도 관리 대상입니다. 기존 방화벽, UAC, 백신 정책을 변경하지 않습니다. 원본 바이너리는 Authenticode 서명이 없으며 정책에서 차단하면 우회하지 않습니다.

agent-desktop은 자체 ref 상태와 Windows의 사용자별 interaction lock을 만들 수 있습니다. 모든 흔적이 지정한 결과 폴더 안에만 생긴다고 보장하지 않습니다. 다른 사용자의 세션과 잠긴 화면, UAC 보안 데스크톱은 관찰 대상이 아닙니다. 원본의 PID 전체 메뉴 탐색도 차단합니다. 명시한 창에 노출되지 않는 메뉴는 미관찰로 남깁니다.

## 검증 범위

별도 합성 화면 비교에서는 부모 창을 다시 읽으면 팝업 단독 관찰이 실패했던 콤보/속성 목록을 확인할 수 있었습니다. 이를 명시적인 부모 범위 옵션으로 반영했습니다. 같은 화면의 공개된 접근성 정보를 더 잘 정리하는 보완이며, 닫힌 메뉴나 Provider가 숨긴 요소를 복원하지는 못합니다.

실제 회사 FX/FxMenuAgent는 다른 PC에 있어 현장 인식률, DPI별 동작과 업무 완료는 검증하지 않았습니다. 테스트 방법과 재현 범위는 [VALIDATION.md](VALIDATION.md)에 기록합니다.
