# 검증 기록

## 0.2.0 조작 연계

2026-11-04. 기존 `observe.py` 읽기 전용 경로를 유지하고 `interact.py`의 창 관찰, 단일 조작과 사후 관찰 경로를 추가했습니다. CUA Driver 없이 고정된 agent-desktop 1.1.0과 Python 표준 라이브러리로 실행했습니다. 회사 FX와 사내 모델 호출은 이 PC에서 수행하지 않았습니다.

### 실제 Windows 합성 앱

`tests/fixtures/ActionFixture.cs`를 로컬 .NET Framework C# 컴파일러로 빌드하고 `tools/smoke_actions.py --include-headed`로 검증했습니다. 에이전트의 성공 응답과 별개로 시험 앱 내부의 상태를 읽어 결과를 확인했습니다. 21개 검증 조건을 모두 통과했으며, 아래 차단 검증도 포함된 수치입니다. 21개 업무 조작이 전부 성공했다는 의미가 아닙니다.

| 검증 | 결과 |
|---|---|
| 관찰만 수행 | 시험 앱 상태 불변 |
| 콤보 Y에서 N으로 변경 | 실제 콤보 N, 래퍼 `completed`와 새 값 `matched` |
| 텍스트 설정과 비우기 | 실제 값 일치와 `completed`. 빈 값은 새 ref의 `get value`로 확인 |
| 체크와 해제 | 실제 상태 변경. 체크는 자동 일치, 해제는 트리에 부정 상태가 없어 래퍼 `executed_unverified` |
| 버튼 실행과 같은 세션 재실행 | 버튼 카운터 한 번 증가, 재실행 차단 |
| 비활성 버튼 | 전달하지 않고 카운터 유지 |
| 지원하지 않는 콤보 select | 값 유지. 전달 여부는 보수적으로 `possibly_dispatched`, 성공으로 처리하지 않음 |
| 메뉴와 하위 메뉴 열기 | 시험 앱에서 열린 상태 확인 |
| 중첩 메뉴 마지막 항목 | Provider가 offscreen으로 보고하여 전달 차단. 선택 성공 아님. 별도 팝업 HWND 직접 관찰도 미지원 |
| 표의 열린 편집기 값 변경 | 편집기 값 일치와 `completed`. EndEdit는 시험 앱 내부 제어로 수행했으며 에이전트의 업무 저장 성공 아님 |
| 같은 PID의 다른 업무 창 | 다른 창에서 얻은 ref 차단. 지정한 창만 조작하고 다른 창의 콤보와 카운터 유지 |
| 물리 텍스트 입력 | `focus --headed`, 새 inspect, `type --headed` 순서로 실제 입력 확인. 래퍼는 `executed_unverified`로 남기고 새 값은 별도 확인 |

표준 WinForms 콤보에서도 `Select` 대신 `SetValue`만 노출될 수 있었습니다. 메뉴 항목을 인식했다는 사실 역시 실행 가능성을 보장하지 않았습니다. 위 결과는 실제 사내 Infragistics, FarPoint, FX/FxMenuAgent 컨트롤의 지원 여부를 대신하지 않습니다.

초기 실행에서는 물리 입력 전에 요소 포커스가 없어 전달이 막혔습니다. 실제 노출된 요소에 명시적으로 포커스를 준 뒤 새 ref로 입력하는 절차를 가이드에 반영했습니다. 엔진의 포커스, 가시성 검사나 회사 보안 정책을 해제하지 않았습니다.

### 코드 및 배포 경계

단위 검사 54개(기존 관찰 19개와 새 조작 35개)를 통과했습니다. 만료와 소비된 세션, 동시 재실행, 다른 창의 ref, 변경된 스냅샷과 프로세스 수명, 보호된 필드, 옵션처럼 보이는 입력값, 타임아웃, Ctrl+C, 사후 읽기 실패, 모호한 컨트롤, 빈 값 및 모순된 응답을 포함합니다. 실행 여부를 알 수 없으면 현재 값이 일치해도 실행 완료로 바꾸지 않습니다.

조작을 시작하기 전에 소비 기록과 전달 불확실 기록을 저장하고, 엔진 응답을 받은 뒤에는 사후 읽기보다 먼저 전달 결과를 저장합니다. 원문 UI와 입력 값은 로컬 파일에 보관합니다. 래퍼에는 네트워크 클라이언트나 외부 모델 호출이 없으며 JEV를 포함하지 않습니다. 원본 Windows 조작/키보드 경로를 검토했으며 텍스트 입력은 SendInput을 사용합니다. 이 결과는 OS 네트워크 차단이나 패킷 캡처를 통한 검증은 아닙니다.

기존 CUA 주요 실행 파일과 설정의 전후 SHA-256을 비교하며, 공개 패키지는 명시한 소스, 테스트 및 고정된 엔진만 포함합니다. 회사 캡처, 실제 업무 결과, REA 원문과 개인 설정은 배포하지 않습니다. 사용 가이드는 오프라인 HTML이며 PowerShell 예제 8개 구문 검사와 넓은 화면/좁은 화면 렌더 검사를 수행했습니다.

재현 명령은 새 로컬 시험 폴더에서 실행합니다. 아래 명령은 시험 창을 만들며 `--include-headed`는 그 창에 포커스와 물리 입력을 허용합니다. .NET Framework 컴파일러는 시험 앱을 빌드할 때만 필요하며 일반 사용에는 Python 3.10 이상이 필요합니다.

```powershell
python -X utf8 -B -m unittest discover -s tests -v
python -X utf8 -B tools/smoke_actions.py --work-dir C:\LocalReview\ActionTest --include-headed
```

## 0.1.1 사용 가이드 추가

처음 사용하는 분을 위한 오프라인 HTML 안내와 CUA Driver/별도 실행 엔진의 차이를 추가했습니다. Windows용 ZIP과 소스 ZIP에 같은 가이드를 넣고, 가이드 단독 HTML도 배포합니다. 관찰 명령과 agent-desktop 1.1.0 바이너리는 유지했습니다. 가이드의 Ctrl+C 중단 경로도 검토해, 사용자 중단 때 로컬 경로가 담긴 Python traceback 대신 고정된 interrupted 응답을 반환하도록 보완했습니다.

사용자 중단 검사 1개를 포함한 19개 회귀 검사와 최종 ZIP의 미존재 앱 관찰 스모크, 내부 SHA-256 및 소스 일치 검사를 통과했습니다. 실제 회사 FX 시험 결과를 새로 추가하는 버전이 아닙니다. 아래 6개 합성 화면 결과는 0.1.0에서 수행한 기록입니다.

## 실제 합성 앱 관찰

자체 WinForms/WPF 시험 앱을 실행해 6개 상태와 총 10개 요청 scope를 관찰했습니다. UI 전환은 시험 앱 내부 제어로 준비했으며 래퍼가 클릭, 키 입력, 펼치기나 스크롤을 보내지 않았습니다. 이 앱은 실제 사내 Infragistics/FarPoint 컨트롤이 아닙니다.

| 상태 | 최종 관찰 |
|---|---|
| A: 자식 없는 WPF peer와 기본 컨트롤 | 창 154노드. Family 콤보와 표 확인. 숨겨진 자식은 만들어 내지 않음 |
| B: 열린 표준 콤보 | 직접 팝업은 inventory에 없어 unavailable. 명시한 부모 159노드에서 N/P와 선택된 N을 확인. 전체 상태 partial |
| C: 별도 검색 모달 | 검색 창과 부모를 구분해 170노드. 두 선택지를 확인 |
| D: 동적 PropertyGrid 편집기 | 편집기와 부모를 구분해 182노드. 코드 H와 표시 Hybrid가 별도 노출됨 |
| E: 스크롤된 표 | 155노드. 행 키와 표/행 역할 확인. 셀 주소 지원으로 확대 해석하지 않음 |
| F: 재생성된 하위 메뉴 | 팝업 자체는 메뉴 항목을 노출하지 않음. 명시한 부모 트리에서 Active sheet와 All sheet를 구분. 두 scope 합계 160노드 |

최종 실제 Windows 세션 실행에서 6개 상태 모두 전경 유지와 기존 CUA 주요 파일/설정 지문 유지를 확인했습니다. 총 10개 요청 scope 중 9개는 트리를 반환했고 B의 직접 팝업 1개는 미관찰이었습니다. 트리를 반환한 사실과 해당 업무 항목을 인식한 사실은 별개입니다.

앞선 샌드박스 실행에서는 전경 변화가 감지된 표본이 있었습니다. 이를 성공으로 합산하지 않았고 `interrupted` 상태와 종료 코드 2를 검증했습니다. 해당 변화의 원인을 특정 앱 동작으로 확정하지 않았습니다. 최종 세션의 결과로 과거 제한을 지우지 않습니다.

## 패키지 검증과 재현

`tools/build.py`는 명시한 소스 목록만 패키징합니다. 원본 캡처, 현장 결과, REA 원문, 개인 설정, 로그와 API 키를 포함하지 않습니다. 바이너리 해시, ZIP CRC, 내부 전체 파일 명세와 SHA-256, 소스 ZIP과 공개 소스의 바이트 일치를 검사합니다. `--check`는 네트워크 없이 실행합니다.

```powershell
python -X utf8 -B tools/build.py --assets LOCAL_ASSET_DIRECTORY --check
```

코드와 패키지 검사는 실제 FX 호환성의 인수 시험을 대신하지 않습니다. 회사 PC의 FX/FxMenuAgent, 물리 DPI 행렬, 실제 업무 저장/조회/Excel 생성은 미검증입니다. 실제 업무 자료는 로컬에만 보관하고 공개 이슈에 첨부하지 않습니다.
