먼저 새 버전이 연결되어 있는지 확인하세요

아직 연결하지 않았다면 0.15.0 배포 ZIP 전체를 새 폴더에 압축 풀고 INSTALL.md를 채팅에 첨부하세요. 기존 사용자도 새 파일만 받는 것으로는 현재 연결이 바뀌지 않습니다.

기존 Driver·등록한 프로그램·저장한 작업·학습 요소를 유지하고 이 버전으로 연결을 갱신해줘. MCP를 다시 연결한 뒤 computer_status의 version이 0.15.0인지 확인해줘.

배포본에 필요한 Python과 도우미가 포함되어 있습니다. 편집창과 녹화창은 MCP가 필요할 때 자동으로 엽니다. 제품 갱신 뒤에는 이전 편집창 대신 새 편집창을 사용하세요.

1. 프로그램을 열고 녹화를 준비하세요

평소처럼 업무 프로그램을 열고 반복할 업무의 시작 화면까지 이동하세요. 채팅에 다음과 같이 요청합니다.

지금 열린 프로그램을 자동화 대상으로 등록하고 프로세스 편집창을 열어줘. 내가 직접 동작을 녹화해서 ‘반복 조회’라는 작업으로 저장할게.

같은 이름의 창이 여럿이면 목록에서 사용할 창을 골라 주세요. 주소나 바로가기로 여는 앱도 등록할 수 있습니다. 시작 프로그램과 실제 업무 창이 다르면 실제 업무 창을 선택하고 여는 주소를 함께 알려주세요. 설정 파일이나 레지스트리를 찾을 필요가 없습니다.

여러 앱을 오가는 작업은 편집창을 열 때 사용할 앱들을 함께 알려주세요. 등록한 앱만 추가하는 경우 같은 MCP 연결에서 사용할 수 있습니다.

2. 기록을 시작하고 직접 작업하세요

  1. 편집창에서 ● 동작 녹화를 누릅니다. 녹화 전에 이미지 캡처와 재생에 필요한 좌표 조건을 점검합니다.
  2. 녹화창에서 기록 시작을 누릅니다. ‘기록 중’이 표시되면 연결한 프로그램에서 원하는 클릭·입력을 수행하세요.
  3. 녹화창은 작아집니다. 화면을 가리면 접어두기를 누르세요. Esc를 누르면 창이 돌아오고 일시정지합니다. 이어서 하려면 다시 기록을 시작합니다.
  4. 필요한 작업을 마치면 기록 마치고 검토를 누릅니다. 기록된 동작은 편집창의 실행 순서에 초안으로 추가됩니다.

실제로 작업하는 녹화입니다. 사용자가 누른 버튼과 입력은 업무 프로그램에 그대로 적용됩니다. 녹화를 취소해도 이미 수행한 작업은 되돌아가지 않습니다. 화면 동영상 파일을 저장하는 기능은 아닙니다.

일반 버튼은 같은 조작 대상을 확인하면 요소로 기록합니다. 마우스를 오래 올려놓지 않고 빠르게 누른 일반 Windows 컨트롤도 실제 클릭 정보를 대조합니다. 읽을 수 있는 비보호 입력칸의 붙여넣기는 적용된 값으로 기록합니다. 같은 입력칸을 W → N으로 바꿨다면 기록 시점의 값과 요소 연결이 확인될 때 각 값을 따로 보존합니다. 정보가 부족한 동작은 이미지 또는 검토가 필요한 단계로 남습니다. 값이 보인다는 이유만으로 지원되지 않는 콤보박스 조작법을 추측하지 않습니다.

3. 순서와 입력값을 확인하고 저장하세요

  1. 실행 순서에서 필요한 동작이 순서대로 들어갔는지 확인합니다. 입력값이 의도한 값인지도 확인하세요.
  2. 자세히 볼 단계를 두 번 클릭합니다. 요소·이미지 등 인식 방식과 대상 정보를 확인할 수 있습니다.
  3. 대상이 잘못됐거나 직접 보완할 단계라면 이 단계만 다시 지정을 누릅니다. 대상과 동작을 다시 정하고 필요한 입력 내용을 지정합니다. 원래 순서와 창 연결은 유지됩니다. 바로 이미지로 고르고 싶으면 옆의 이미지로 다시 지정을 누르세요.
  4. 이미지 단계의 대상만 바꾸는 경우 원래 동작은 유지됩니다. 입력 단계는 해당 입력칸의 전체 내용을 바꿀 값이 맞는지 검토하세요. 불필요한 단계는 삭제합니다.
  5. 누락 경고 확인이 보이면 빠진 동작과 이유를 읽고 필요한 단계를 보완합니다. 경고를 확인하는 것만으로 빠진 동작이 복원되지는 않습니다.
  6. 프로세스 이름을 적고 프로세스 저장을 누릅니다. 채팅에서 저장 완료와 저장한 이름을 확인하세요.

저장 자체는 작업을 재실행하지 않습니다. 이미 저장한 작업은 “저장한 ‘반복 조회’를 복사해서 편집창으로 열어줘”라고 요청하면 원본을 보존하고 새 작업으로 저장할 수 있습니다.

한 번에 최대 12개 동작을 기록하며, 확인·대기를 포함한 프로세스는 최대 30단계입니다. 기존 단계가 있으면 남은 범위 안에서 기록합니다.

버튼을 못 읽으면 이미지로 선택하세요

  1. 편집창의 이미지로 선택을 누릅니다. 일반 요소 선택에서 조작 대상을 확인하지 못한 경우에도 이미지 선택으로 이어질 수 있습니다.
  2. 대상 창을 가져와 캡처를 누릅니다. 표시된 이미지에서 사용할 버튼과 주변 내용을 사각형으로 드래그합니다.
  3. 미리보기에서 실제로 누를 위치를 지정하고 확정합니다. 누를 위치는 버튼 안에 있어야 합니다.

같은 버튼이 여러 줄에 반복되면 아이콘만 선택하지 말고 해당 줄의 이름처럼 구분되는 내용을 함께 포함하세요. 입력칸은 바뀌는 입력 글자나 선택 강조 대신 고유한 주변 이름을 포함하고 실제 입력칸 안을 클릭 위치로 지정하세요.

매번 현재 창의 이미지에서 대상을 다시 찾습니다. 옛 바탕화면 좌표를 그대로 누르지 않습니다. 창을 옮겼다는 이유만으로 다시 녹화할 필요는 없습니다. 다만 배율·모양이 바뀌었거나 다른 창에 가려졌다면 현재 상태에서 다시 확인해야 합니다. 후보가 여러 개이면 임의로 하나를 누르지 않습니다.

선택창에서 ‘버튼’이라고 읽혀도 실제 조작 도구가 같은 대상을 제공하지 않으면 이미지로 전환될 수 있습니다. 이는 ‘아무 정보도 못 읽었다’는 뜻과 다릅니다. 다른 창이나 커서 표시 도구가 겹치면 대상 프로그램 자체의 이미지로 캡처를 시도합니다. 프로그램이 이 방식에 응답하지 않거나 빈 이미지를 반환하면 잘못된 이미지를 저장하지 않습니다. 캡처가 실패하면 이유와 오류 코드를 확인하고 같은 안내를 반복하지 않도록 요청하세요.

4. 저장한 작업을 실행하세요

녹화를 시작했던 화면과 입력 상태를 준비한 뒤 요청합니다.

저장한 ‘반복 조회’를 실행해줘. 예상과 다르면 멈추고 어느 단계인지 알려줘. 화면 확인이 필요하면 이 PC의 확인 창으로 보여줘.

화면 확인 창이 뜨면 이 단계의 결과가 맞는지 보고 확인 완료 또는 결과가 다름을 누릅니다. 채팅 클라이언트는 이 확인 기록을 읽은 뒤 같은 실행을 이어갑니다. 확인 버튼 자체가 다음 업무 동작을 즉시 실행하는 것은 아닙니다.

기본값에서는 모델에 이미지를 자동 전달하지 않습니다. 이미지 비교는 PC 안에서 하고, 사람이 볼 화면은 별도 창에 표시합니다. 텍스트 전용 모델에 이미지 지원을 새로 설정할 필요가 없습니다. 이미지 입력을 지원한다고 확인된 모델로 직접 화면을 읽히려는 경우에만 채팅에서 이미지 전달을 요청하세요.

이미지 동작과 직접 화면 확인을 사용하는 작업은 대상 창을 앞으로 가져올 수 있습니다. 요소만 사용하는 작업은 기본적으로 배경 실행을 사용합니다. 마우스 이동이 눈에 보이지 않아도 버튼에 직접 동작을 요청할 수 있습니다.

중간에 멈추면, 그 실행에서 이어가세요

방금 중단한 실행을 이어가고 싶어. 현재 화면과 입력 전달 여부를 먼저 확인해줘. 입력하지 못한 단계만 같은 실행에서 진행하고, 완료한 앞 단계는 반복하지 마.

아직 입력을 보내지 않았다는 기록이 있으면 앞 단계의 상태와 현재 준비 상태를 다시 읽고 해당 단계부터 진행합니다. 이미 보냈거나 전달 여부가 불명확하면 결과 확인부터 하며 같은 입력을 자동 반복하지 않습니다.

첫 대상부터 못 찾으면 녹화 당시의 시작 화면인지 확인하세요. 전체 실행을 새로 시작하면 앞의 입력도 다시 실행될 수 있으므로, 중단한 작업은 먼저 같은 실행 이어가기를 요청하세요.

기다림과 결과 확인을 더 편하게 만드세요

추가할 단계쓰는 상황
요소·이미지가 나타날 때까지 대기다음 화면이나 버튼이 준비되면 진행합니다.
완료 조건이 될 때까지 대기지정한 값·체크·활성 상태가 맞으면 바로 진행합니다. 제한 시간 안에 맞지 않으면 멈춥니다.
정해진 시간 대기필요한 경우에만 0~60초를 지정합니다.
화면을 보고 직접 확인동작 뒤 화면 확인 창에서 사람이 결과를 확인합니다.
선택한 요소의 변화로 자동 확인실제로 바뀌는 완료 요소와 예상 값을 지정합니다. 동작 전후의 새 변화가 확인되면 이어갑니다.

버튼을 눌렀다는 사실과 업무가 끝났다는 사실은 다릅니다. 자동 완료 조건을 정하지 않은 기록은 직접 확인 단계를 유지합니다. 조회 전부터 보이던 ‘완료’ 문구나 화면 줄무늬만으로 새 조회 성공을 판단하지 않습니다.

한 번 검증된 같은 작업은 빠른 반복 경로를 사용할 수 있지만 결과 확인은 유지합니다. 앱의 서버 처리 시간은 남습니다. 불필요한 고정 대기는 ‘완료 조건이 될 때까지 대기’로 바꾸면 준비됐을 때 바로 이어갈 수 있습니다.

잘 안될 때는 이 부분만 확인하세요

증상다음 행동
요소 선택창이 안 보임버전·도우미 시작 오류·실제 표시 상태를 확인하도록 요청하세요. 보이지 않는 창에서 F8을 반복할 필요가 없습니다.
일부 단계만 잘못 기록됨해당 단계를 두 번 클릭하고 ‘이 단계만 다시 지정’을 사용하세요. 다른 단계는 유지합니다.
이미지를 못 찾거나 후보가 여러 개시작 화면, 대상 창 가림, 이미지 모양·배율을 확인하고 고유한 주변 이름을 포함해 그 단계만 수정하세요.
이미지 재생을 지원하지 않는다는 안내구형 DPI 비인식 앱은 실제 캡처·입력 좌표가 맞는 단일 100% 모니터 조건에서만 이미지 입력을 허용합니다. 그 외에는 요소 방식을 사용하거나 직접 보완합니다. 레지스트리를 자동 변경하지 않습니다.
닫힌 팝업의 버튼을 요소로 확인하지 못함녹화가 끝났을 때 이미 닫힌 팝업은 조작 대상을 다시 검증하기 어려울 수 있습니다. 기록된 이미지나 해당 단계 보완을 사용합니다.
새 기능이 안 보임현재 computer_status.version이 0.15.0인지 확인하고 새 연결에서 편집창을 여세요.

비밀번호 입력과 대상이 불명확한 원시 키 입력은 저장하지 않습니다. 관계가 확인되지 않은 팝업·다른 프로그램의 동작, 드래그와 일부 특수 입력은 보완이 필요합니다. 녹화된 초안을 검토해 실제 필요한 동작이 모두 포함됐는지 확인하세요.

표의 결과는 파일로 확인할 수도 있습니다

화면의 표를 읽기 어려우면 요청한 업무에 엑셀·CSV 내보내기를 포함할 수 있습니다. 정확한 결과 폴더와 확인할 열을 알려주세요. 도구는 내보내기 전 파일 기준을 기록하고, 이번에 바뀐 파일에서 비어 있지 않은 데이터 행 전체를 비교합니다. 파일 검증 도구 자체는 Excel이나 매크로를 실행하지 않습니다.

결과 폴더는 내가 알려줄게. 내보내기 전에 기존 파일을 기록해줘. 이번 결과 파일에서 ‘분류’ 열 전체가 ‘W’인지 확인해줘. 화면 조건과 파일 열의 대응 관계가 불명확하면 추측하지 마.

CSV/XLSX 파일 최대 64MiB, 100,000행·5,000,000셀 등의 한도가 있습니다. 자세한 범위는 연결 도구 안내를 확인하세요. 파일 값 확인만으로 전체 업무 완료를 선언하지 않습니다.
