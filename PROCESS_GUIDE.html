COMPUTER USE MCP · 0.12.0

한 번 가르친 작업을
확인하면서 빠르게 반복하세요

버튼 정보를 읽을 수 없는 화면은 이미지를 직접 지정합니다. 반복 작업은 동작 녹화로 초안을 만들고, 목록과 누락 안내를 확인한 뒤 저장합니다. 한 번 검증된 작업은 다음부터 필요한 요소를 좁혀 읽어 실행합니다.

1. 먼저 새 버전으로 연결하세요

이 안내는 0.12.0 배포본 기준입니다. GitHub 릴리스에서 새 ZIP을 받으세요. 이전 공개 버전 0.11.1에는 이번 빠른 반복·결과 파일 검증이 없습니다. 메인 앱은 이번 변경 대상이 아닙니다.

새 배포 ZIP 전체를 새 폴더에 압축 해제합니다. INSTALL.md를 채팅에 첨부하고 아래와 같이 요청하세요. 기존 연결이 옛 폴더를 가리키면 새 기능이 보이지 않습니다.

기존 Driver·프로그램·저장한 작업과 학습 요소를 유지하고, 이 버전으로 연결을 갱신해줘. MCP를 다시 연결한 뒤 computer_status의 version이 0.12.0인지 확인해줘.

처음 연결한다면 처음 연결하기 안내를 이용하세요. 이미지 도구와 프로세스 편집 창은 MCP가 필요할 때 자동으로 엽니다. 별도로 Python을 설치하거나 명령어를 입력할 필요가 없습니다.

2. 프로세스 편집 창을 여세요

사용할 프로그램을 열고 필요한 화면까지 이동한 다음, 채팅에서 요청합니다. 처음 쓰는 프로그램이면 먼저 실행파일을 등록합니다.

지금 열린 프로그램으로 반복 작업을 만들고 싶어. 프로세스 편집 창을 열어줘. 요소는 내가 직접 선택하거나 동작을 녹화할게.

여러 프로그램을 사용할 때에는 시작할 때 프로그램들을 함께 알려주세요. 같은 요청을 반복해 편집 창을 여러 개 열지 않아도 됩니다.

3. 버튼을 인식하지 못하면 이미지로 선택하세요

  1. 편집 창에서 대상 프로그램을 고르고 이미지로 선택을 누릅니다. 일반 요소 직접 선택으로 선택했지만 버튼 정보를 연결하지 못한 경우에도 이미지 선택으로 이어집니다.
  2. 이미지 선택 창의 안내에 따라, 사용할 버튼과 주변 내용을 포함하도록 사각형 영역을 드래그합니다.
  3. 선택한 이미지의 미리보기에서 실제로 누를 위치를 지정합니다. 큰 영역을 선택했더라도 클릭할 곳은 버튼 안이어야 합니다.
  4. 미리보기와 클릭 위치를 확인하고 선택을 확정합니다. 편집 창에서 이미지와 인식 방식을 확인합니다.
  5. 클릭·오른쪽 클릭·입력·키보드 등 필요한 동작을 고르고 이 동작을 다음 단계로 추가를 누릅니다.
같은 버튼이 여러 줄에 반복되나요?
삼각형이나 돋보기 모양만 선택하지 말고 해당 줄의 이름 같은 구분 정보를 함께 포함하세요. 그런 다음 미리보기에서 실제 버튼을 클릭 위치로 지정합니다. 같은 후보가 여러 개이면 자동으로 아무 버튼이나 누르지 않습니다.

저장한 위치를 그대로 누르는 방식이 아닙니다. 매번 현재 창의 이미지에서 대상을 다시 찾습니다. 창을 옮겼다고 옛 바탕화면 좌표를 누르지 않습니다. 버튼 모양·테마·화면 배율이 크게 바뀌거나 다른 창에 가려지면 다시 선택하거나 창을 앞으로 가져와야 할 수 있습니다.

4. 직접 하는 동작을 녹화하세요

  1. 편집 창에서 ● 동작 녹화를 누릅니다.
  2. 녹화 창에서 범위를 확인하고 기록 시작을 누릅니다. 녹화 표시가 보인 뒤 연결한 프로그램을 직접 조작합니다.
  3. 버튼을 클릭하거나 입력하고, 필요한 키·스크롤 동작을 수행합니다. 잠깐 다른 일을 해야 한다면 일시정지를 사용합니다.
  4. 필요한 작업을 끝내면 기록 마치고 검토를 누릅니다. 녹화된 동작이 편집 창의 실행 순서에 초안으로 추가됩니다.
  5. 각 단계의 대상·동작·입력값을 확인합니다. 단계를 두 번 클릭하면 기록한 대상이 보입니다. 이미지 범위가 너무 좁거나 같은 버튼이 반복되면 이미지 대상 다시 선택으로 대상만 바꿀 수 있습니다. 불필요한 단계는 삭제하고 순서를 바꿉니다. 기록 내용 확인 필요인 단계는 선택해서 입력 내용 지정을 누르거나 삭제합니다. 입력 내용을 지정할 수 없는 단계는 삭제한 뒤 대상과 동작을 직접 추가합니다.
  6. 누락 경고 확인 버튼이 보이면 눌러 빠진 부분을 확인합니다. 필요한 단계를 직접 추가하거나 삭제한 뒤 전체 순서가 맞으면 프로세스 이름을 적고 프로세스 저장을 누릅니다. 경고를 확인했다고 빠진 동작이 자동으로 복원되지는 않습니다.

녹화 중에는 사람이 직접 누른 동작이 실제 프로그램에 적용됩니다. 녹화 자체를 취소해도 이미 사람이 수행한 작업이 되돌아가지는 않습니다. 저장 전에 초안을 확인하세요.

전체 화면 동영상을 저장하는 기능은 아닙니다. 연결한 창에서 수행한 지원 동작을 단계로 정리합니다. 지원되는 입력·체크는 요소와 최종값을 대조하고, 정보가 부족한 대상은 이미지나 직접 확인할 단계로 남깁니다. 콤보박스는 값이 보여도 실제 선택·확정 방법을 확인하지 못하면 자동 선택 방법을 추측하지 않습니다. 다른 앱이나 연결하지 않은 새 창으로 이동하면 그곳의 동작은 수집하지 않습니다. 비밀번호 입력은 기록하지 않으며, 입력칸 종류를 확인하지 못한 경우에도 원시 키 입력을 저장하지 않습니다.

입력칸은 검토가 더 필요할 수 있습니다. 자동으로 잡은 이미지에 입력 글자나 선택 강조가 포함되면, 다음 실행에서 이미지가 달라져 찾지 못할 수 있습니다. 해당 단계를 두 번 클릭하고 이미지 대상 다시 선택으로 바뀌지 않으면서 해당 입력칸만 구분하는 고유한 주변 이름과 클릭 위치를 다시 지정하세요. 비슷한 빈 입력칸의 테두리만 선택하면 다른 입력칸으로 오인식할 수 있습니다. 입력 글자뿐 아니라 포커스에 따라 색이 바뀌는 테두리도 피하세요. 일반 요소 선택으로 읽을 수 있는 입력칸은 요소 방식으로 구성할 수도 있습니다.

드래그·특수 단축키·새 팝업 등 자동 기록하기 어려운 동작은 확인이 필요합니다. 한 번에 최대 15개 동작을 기록하며, 화면 확인을 포함해 프로세스는 최대 30단계입니다. 기존 단계가 있으면 남은 만큼 기록합니다. 녹화가 모든 프로그램의 모든 동작을 완벽하게 재현한다는 뜻은 아닙니다. 누락·확인이 필요한 단계는 저장 전에 해결하세요.

5. 기다림과 화면 확인을 추가하세요

기능사용하는 상황
요소·이미지가 나타날 때까지 대기다음 버튼이나 화면이 준비될 때까지 기다립니다. 대상이 하나로 확인되지 않으면 다음 동작을 진행하지 않습니다.
완료 조건이 될 때까지 대기선택한 요소의 값·체크·활성 상태가 지정한 조건이 되는지 읽습니다. 조건이 맞으면 바로 진행하고, 최대 시간까지 맞지 않으면 멈춥니다.
정해진 시간 대기몇 초 후 다음 단계를 실행합니다. 0~60초를 지정할 수 있습니다.
화면 캡처 후 확인현재 창의 이미지를 채팅에 보여주고 사용자가 결과를 확인할 때까지 멈춥니다.

이미지 기반 동작 뒤에는 화면 확인 단계가 함께 추가됩니다. 버튼 위치를 찾았다는 것과 업무가 성공했다는 것은 다르므로, 결과 화면을 보고 이어갑니다. 이미지 확인을 자동 승인하거나 캡처 성공만으로 작업 완료라고 표시하지 않습니다.

6. 저장한 프로세스를 실행하세요

처음은 일반 실행, 성공한 다음부터는 자동으로 빠른 반복을 사용합니다. 같은 작업 순서·변수 구성·프로그램 설정·실행파일을 확인합니다. 이번 입력값을 바꿨다면 그 새 값으로 결과를 검증합니다. 버튼마다 채팅에 다음 명령을 다시 입력할 필요는 없습니다.

저장한 “반복 조회 작업” 프로세스를 실행해줘. 검증된 작업이면 빠른 반복으로 진행하고, 예상과 다르면 멈춰줘. 이미지 단계의 화면 확인이 필요하면 나에게 보여주고 기다려줘.

화면이 원하는 결과로 바뀌었으면 “화면 확인했어. 이어서 진행해줘.”라고 말합니다. 잘못된 화면이면 계속하지 말고 중지한 뒤 단계를 수정합니다. 실행 중 결과를 확인하지 못한 입력을 자동으로 반복하지 않습니다.

재실행 전에는 녹화를 시작했던 화면과 입력 상태로 준비하세요. 입력 내용 지정은 해당 입력칸의 전체 내용을 바꾸는 방식입니다. 클릭할 때 바뀌는 글자까지 이미지에 포함했다면 원래 화면과 달라 대상을 못 찾을 수 있습니다. 프로그램과 MCP를 다시 열어도 프로세스는 유지됩니다. 수정할 때에는 “저장한 프로세스를 복사해서 편집 창으로 열어줘”라고 요청하세요. 원본을 보존하고 새 프로세스로 저장합니다.

7. 기다림을 줄이되 이번 결과는 확인하세요

빠른 반복은 각 동작의 결과 확인을 생략하지 않습니다. 현재 창에서 필요한 요소를 우선 읽습니다. 실행 결과의 execution.mode로 일반 실행(standard)과 빠른 실행(fast)을 구분할 수 있습니다.

실패하거나 확인하지 못한 실행 뒤에는 빠른 반복 자격을 해제합니다. 다음 실행은 다시 일반 방식으로 확인하며, 실패한 입력을 자동으로 다시 보내지 않습니다. 직접 “이번에는 일반 방식으로 다시 확인해줘”라고 요청할 수도 있습니다. 채팅 도구의 기본 설정은 execution_mode: auto이고, 일반 방식 요청은 execution_mode: standard입니다.

작업에 넣어둔 고정 대기와 프로그램의 서버 처리 시간은 그대로 남습니다. 불필요한 고정 대기 단계를 완료 조건이 될 때까지 대기로 바꿔달라고 요청하세요. 매번 조회 전부터 보이던 ‘완료’ 문구가 그대로인 것은 새 조회 성공의 증거가 아닙니다.

조회 버튼을 누른 뒤 이번 결과가 새로 나온 것을 확인해줘. 동작 전 상태와 달라져야 통과하는 완료 조건을 넣어줘. 이미 있던 완료 문구나 화면 줄무늬만으로 성공 처리하지 마.

기술적으로는 완료 조건의 require_change: true를 사용합니다. 실제로 바뀌는 결과 번호·건수·상태가 필요하며, 기준 상태가 없으면 변화 확인을 성공으로 처리하지 않습니다. 이미지 동작 뒤에는 여전히 사용자가 화면을 확인해야 합니다.

8. 엑셀·CSV로 결과를 확인하려면

화면의 표를 읽기 어렵다면, 프로그램의 내보내기를 작업에 포함할 수 있습니다. 먼저 정확한 결과 폴더와 확인할 열을 정하세요. 내보내기는 파일을 만들고 경우에 따라 Excel을 여는 별도 동작입니다.

결과 폴더는 내가 알려줄게. 내보내기 전에 기존 파일을 기록해줘. 이번에 만든 파일에서 ‘분류’ 열의 모든 데이터가 ‘W’인지 확인해줘. 시트가 여러 개거나 열 이름이 불명확하면 추측하지 마.
  1. computer_prepare_result로 지정 폴더의 기존 파일 기준을 준비합니다.
  2. 요청한 내보내기를 실행합니다.
  3. computer_verify_result로 받은 확인 번호와 정확한 파일 이름·열·예상값을 확인합니다. 헤더가 2행이면 헤더 행도 알려줍니다.

내용이 그대로인 기존 파일이나 수정 시간만 바뀐 파일은 새 결과로 인정하지 않습니다. 비어 있지 않은 데이터 행 전체를 비교하고, 서식만 있는 빈 행은 건수에서 제외합니다. 파일 확인 도구는 Excel·COM·매크로를 실행하지 않습니다.

파일의 값 확인이 곧 전체 업무 성공은 아닙니다. 화면에서 고른 조건과 확인할 파일의 열이 서로 대응하는지, 이번 조회가 완료됐는지도 확인해야 합니다. 이 파일 도구만으로 task_verified가 true가 되지 않습니다.

파일 최대 64MiB, XLSX 내부 XML 하나 128MiB·압축 해제 합계 256MiB, 최대 100,000행·5,000,000셀입니다. 기준 폴더는 최대 2,000항목·기존 파일 합계 256MiB이고 확인 번호는 현재 세션에서 10분간 유효합니다. 수식으로 계산한 검증 열·외부 링크 등은 지원하지 않습니다. 한도를 넘으면 부분 성공으로 처리하지 않습니다.

주소나 인자가 있어야 열리는 프로그램인가요?

설정 창의 프로그램 추가/수정 → 여는 방법 · 선택을 사용하세요. 실제 업무 창의 EXE는 ‘열린 창에서 선택’으로 고르고, 주소로 여는 앱은 실행 주소를 입력합니다. EXE의 인자가 필요하면 한 줄에 하나씩, 시작 폴더는 필요한 경우에만 적습니다. 주소 실행과 EXE 인자·시작 폴더를 동시에 지정하지 않습니다.

이 앱은 내가 알려주는 주소로 열어야 해. 실제 열린 창에서 실행파일을 확인해 등록하고, 이 주소를 여는 방법으로 저장해줘.

등록 후 MCP를 다시 연결하세요. Windows에 주소를 전달했다는 것과 실제 업무 화면이 준비됐다는 것은 따로 확인합니다. 자세한 내용은 프로그램 실행 방식 안내를 참고하세요.

잘 안될 때 확인하세요

요소 선택 창이 안 보일 때: “computer_status로 버전과 teaching_support를 확인하고, 실제 오류 코드와 실패 단계를 보여줘. F8 안내를 반복하지 마”라고 요청하세요. UIA는 선택 창을 지원합니다. 연결된 폴더가 이전 버전이거나 선택 도우미 파일이 빠졌는지 먼저 확인합니다. 파일 존재 확인은 실제 창 표시 확인과 다릅니다.

상황해결 방법
같은 이미지가 여러 개 발견됨주변 이름 등 구분되는 부분을 함께 선택하고 클릭 위치를 다시 지정합니다.
이미지를 찾지 못함대상 창을 앞으로 가져오고, 화면 상태·테마·배율이 달라졌는지 확인합니다. 현재 화면에서 이미지를 다시 선택합니다.
녹화한 입력 내용을 확인해야 함해당 단계를 선택해 넣을 내용을 직접 지정하거나 불필요한 단계를 삭제합니다.
화면 배율을 지원하지 않는다는 안내일부 구형 프로그램은 Driver가 캡처한 크기와 입력 좌표가 일치하지 않아 이미지 클릭을 지원하지 않습니다. UIA 요소 선택을 사용하거나 해당 프로그램은 별도 검증이 필요합니다.
새 버튼이 보이지 않음기존 창을 닫고 새 배포 폴더로 MCP 연결을 갱신했는지, computer_status의 버전이 0.12.0인지 확인합니다.

채팅의 computer_teach_element는 Windows가 제공하는 요소 정보를 학습합니다. 이번 이미지 선택·녹화는 computer_process_editor로 여는 프로세스 편집 창에서 사용합니다.

실행 중 Windows의 일반 Edit 비밀번호 입력칸으로 확인되면 이미지 방식의 문자·키 입력을 차단합니다. 모든 앱의 자체 비밀번호 칸을 알아보는 기능은 아닙니다.

이미지 검색과 녹화는 PC 안에서 처리하며 외부 API나 LLM을 호출하지 않습니다. 프로세스 파일에는 직접 선택한 이미지와 입력 내용이 저장됩니다. 실행 중 확인용 이미지는 연결한 MCP 클라이언트로 전달되므로 해당 앱의 LLM 연결 설정을 따릅니다.
