COMPUTER USE MCP · 0.19.2

녹화부터 반복 실행까지

단계 → 입력값 → 스킬 보기. 한 편집창에서 필요한 것만 확인하세요.

0.19.2는 SmartFX와 FXMenuAgent의 업무 창 연결, 드롭다운 및 메뉴 녹화, 읽기 전용 접근성 진단을 보완합니다. 기존 녹화와 로컬 데이터 정책을 유지하며, 적용 범위와 남은 제한은 검증 기록에서 확인하세요. 실제 게시 상태와 배포 파일은 GitHub Release를 기준으로 합니다.

기존 연결을 갱신할 때

새 ZIP 전체를 새 폴더에 풀고 연결 안내로 기존 설정과 저장 작업을 유지해 갱신한 뒤 MCP 연결을 다시 시작하세요. 0.19.0에서 로컬 설치 진단이 필수 도구 누락으로 실패하던 오류도 수정했습니다. 로컬 데이터 정책을 바꾸거나 기존 작업을 삭제할 필요는 없습니다.

1. 프로그램을 고르고 기록하기

프로세스 편집창을 열어줘.

등록된 프로그램을 로컬 창에서 선택합니다. 여러 앱을 오가면 사용할 프로그램을 함께 고릅니다. 등록이 필요하면 EXE·업무 주소 또는 .appref-ms의 실제 업무 창을 연결합니다.

  1. 동작 녹화 → 기록 시작을 누릅니다.
  2. 평소처럼 클릭·입력하고 기록 마치고 검토를 누릅니다.
  3. 단계 탭의 동작을 두 번 클릭해 대상·값·완료 조건을 확인합니다.

녹화 중 실제 업무 동작이 수행됩니다. 취소해도 이미 수행한 동작은 되돌아가지 않습니다. 마우스를 올린 사실만으로 클릭이나 선택값을 기록하지 않습니다.

녹화를 취소하거나 가져오기에 실패하면 이전 초안을 유지합니다. 보완할 단계가 있어도 초안으로 저장할 수 있습니다. 원본이 남아 있으면 최근 녹화 다시 분석을 먼저 검토하세요. 누락 경고를 확인한 사실이 기록되지 않은 입력을 복원하지는 않습니다.

작은 아이콘이 반복되면 고유한 줄 이름 등 주변 문맥을 함께 지정합니다. ‘가림’ 안내만으로 사용자가 다른 앱으로 가렸다고 단정하지 않으며 드롭다운·중첩 메뉴 관계도 확인합니다. 모호한 첫 후보를 임의로 누르지 않습니다.

3. 실행할 때 바꿀 값 지정하기

  1. 실제 입력 단계에서 실행할 때 바꿀 값으로 사용을 지정합니다.
  2. 입력값 탭에서 이름·형식·필수 여부·기본값을 정합니다.
  3. 사용 단계 목록을 보고 같은 값이 연결된 곳을 확인합니다.

텍스트·날짜·선택값·숫자·정수·참/거짓·목록을 구분합니다. 목록의 순서와 반복 값은 유지합니다. 이미지 클릭은 특정 그림을 누르는 동작이므로 값만 바꿔 다른 항목으로 전환할 수 없습니다.

그림으로 만든 입력칸처럼 최종 값을 읽을 수 없는 경우 해당 단계의 위치와 값을 직접 보완합니다. 확인되지 않은 키 입력을 임의로 복원하지 않습니다. 업무용 비밀번호를 스킬이나 일반 기본값에 넣지 마세요.

4. 시험하고 저장하기

시험 실행을 누르고 로컬 입력폼에 값을 넣습니다. 입력값·선택 상태·완료 문구 등 구체적인 조건으로 확인하세요. 이미지 일치나 팝업 존재는 업무 결과 성공과 다릅니다.

0.19.1부터 저장 직후 시험할 때 녹화 중 닫힌 팝업을 시작 창으로 검사하지 않습니다. 작업이 팝업을 여는 단계에서 현재 창을 다시 찾으므로 이 오류 때문에 다시 녹화할 필요는 없습니다. 기본 업무 창이 닫혔다는 안내가 나오면 입력은 시작되지 않습니다. 프로그램 창을 다시 연결한 뒤 시험하세요.

프로세스 저장 후에도 창을 유지해 추가 수정할 수 있습니다. 저장 전 변경이 남으면 닫을 때 안내합니다. 기존 작업 수정은 새 revision으로 저장하며 이전 버전은 보존합니다.

처음 실행하는 작업·변경된 입력의 확인을 생략하지 않습니다. 고정 대기 시간을 늘리는 대신 결과 요소나 완료 조건을 기다리도록 구성하면 준비된 시점에 진행할 수 있습니다.

5. 스킬 전체를 보고 내보내기

스킬 보기 → 미리보기 갱신 → 보이는 내용 내보내기를 사용합니다. 미리 본 파일 그대로 저장하며 자동 설치하지 않습니다. 편집을 바꾸면 저장과 미리보기를 다시 해야 합니다.

스킬에는 불투명한 작업 ID와 고정 revision의 호출 안내가 들어갑니다. 업무명·기본값·이미지·내부 경로는 넣지 않습니다. 파일만 다른 PC로 옮기면 원래 작업은 함께 옮겨지지 않습니다. 같은 MCP에 저장 작업과 등록 프로그램이 있어야 합니다.

6. 다음에는 로컬 입력창으로 실행하기

저장한 작업을 실행해줘. 입력값은 이 PC의 창에서 넣을게.

실제 값은 로컬 입력폼에서 받습니다. 실행은 처음 시작한 revision과 값으로 고정되며 중간 편집이 그 실행에 몰래 반영되지 않습니다.

방금 멈춘 것과 같은 실행을 이어가줘. 이미 보낸 입력은 반복하지 말아줘.

이 요청으로 완료 기록을 보존해 이어갑니다. 전달이 불명확한 입력은 결과부터 확인하며 사람 확인은 실제 확인이 필요합니다. 새 실행은 앞 동작도 다시 수행할 수 있으므로 반복 제출하지 마세요.

로컬과 연결 모드를 구분하세요

기본 로컬 모드에서는 상세 화면·업무 텍스트·입력값을 채팅에 내보내지 않습니다. 기존 모델 화면 판정 단계가 있으면 첫 입력 전에 멈추며, 편집창에서 자동 조건 또는 직접 확인으로 새 revision을 저장해야 합니다.

관리자가 명시한 connected 모드는 검토된 사내 클라이언트에서 말로 직접 조작하거나 모델이 화면을 판정하는 기존 경로입니다. 화면·텍스트가 그 클라이언트로 전달될 수 있으므로 로컬 전용 보장은 적용되지 않습니다. 이미지 전달 요청만으로 정책이 바뀌지 않습니다.

이 MCP는 사용자 채팅·다른 도구·업무 앱의 통신 전체를 차단하지 않습니다. 회사 밖 통신 제한은 클라이언트·모델·네트워크 정책에서도 적용해야 합니다.

기록과 결과 파일은 유지됩니다

캡처와 임시자료는 실행별 폴더에 모입니다. 사용이 끝난 임시파일은 도우미 종료 후 정리하고, 완성 작업에 반영된 복구용 원본은 저장 후 7일이 지나면 정리합니다.

재생 기준 이미지·저장 작업·이전 revision·스킬·실제 Excel/PPT 결과는 자동 삭제하지 않습니다. 초안·저장 실패 원본·잠긴 파일은 보존합니다. 자동화 중지는 업무 앱 강제 종료가 아닙니다.
