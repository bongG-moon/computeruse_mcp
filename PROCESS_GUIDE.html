COMPUTER USE MCP · 0.16.0 사용 안내

말로 부탁하거나,
내가 하는 작업을 기록하세요.

버튼 찾기, 입력, 결과 확인, 반복 실행을 연결합니다.
사용자는 설정 파일이나 창 번호를 다루지 않고 채팅과 편집창으로 진행합니다.

이 문서는 0.16.0의 기능 안내입니다. 자동 검사 1,327개 중 1,325개 통과·2개 조건부 제외, MuMu 저장 작업의 이어가기와 새 실행은 각각 4/4단계를 완료했습니다. 원래 녹화에는 한 단계의 수동 보완이 필요했습니다. 배포 파일과 공개 상태는 Releases, 실제 앱별 시험 범위는 검증 기록에서 확인하세요.

처음에는 연결 한 번만

  1. 받은 ZIP 전체를 계속 사용할 폴더에 압축 풉니다.
  2. INSTALL.md를 채팅에 첨부하고 아래 문장을 보냅니다.
  3. 연결 결과와 버전을 확인하면 준비가 끝납니다. 편집창과 Driver는 필요할 때 MCP가 엽니다.
이 안내대로 화면 작업 기능을 연결해줘. 기존 모델 설정과 다른 MCP는 유지하고, 없는 정보만 물어봐줘.

Driver가 별도 배포되었다면 받은 파일의 위치를 알려주세요. 관리자 연결 때 Windows UAC 확인이 나타날 수 있습니다. 기존 사용자는 “기존 프로그램과 저장 작업을 유지하고 이 버전으로 갱신해줘”라고 요청하세요. 새 파일을 받는 것만으로 기존 실행 중인 MCP가 바뀌지는 않습니다.

사용할 프로그램을 알려주세요

메모장, 계산기, Microsoft Store, Chrome 중 이 PC에 있는 프로그램을 등록해줘.

기본 앱은 실제 설치 정보를 찾아 등록합니다. 다른 프로그램은 평소처럼 열고 “지금 열린 프로그램을 등록해줘”라고 말하세요. 같은 이름의 창이 여러 개면 사용할 창을 고릅니다. EXE 경로·실행 인자·여는 주소를 알고 있다면 함께 알려줘도 됩니다.

등록은 실행과 별개입니다. 이미 열린 업무 창을 우선 사용하며, 앱을 찾기 위해 사용자 폴더 전체를 검색할 필요가 없습니다.

방법 1 · 대화로 실행

지금 할 일을 말하세요

현재 화면에서 대상을 찾고 필요한 동작을 한 뒤 결과를 확인합니다.

계산기에서 25 × 4를 계산하고 결과가 100인지 확인해줘.
MuMu 맨 위 첫 번째 줄의 실행 버튼을 눌러줘. 실행된 화면까지 확인해줘.

그림으로 그린 버튼처럼 요소 정보가 부족하면 이미지로 찾을 수 있습니다. 연결 모델이 이미지 입력을 지원한다면 “이 창의 화면 이미지를 사용해줘”라고 요청하세요.

방법 2 · 기록해서 반복

직접 한 번 보여주세요

실제로 작업하는 동작을 기록하고 편집창에서 검토해 저장합니다.

지금 열린 프로그램으로 프로세스 편집창을 열어줘. ‘반복 조회’를 만들게.

녹화 · 요소 선택 · 이미지 선택 · 값 수정 · 시험을 한 편집창에서 진행합니다. 나중에는 저장한 이름으로 실행합니다.

저장한 ‘반복 조회’를 이번에는 조건 N으로 실행해줘.

녹화 → 검토 → 시험 → 저장

  1. 시작 화면 준비: 앱을 다음에도 반복할 시작 화면으로 놓습니다. 여러 앱을 오갈 작업이면 사용할 앱을 함께 알려주세요.
  2. ● 동작 녹화 → 기록 시작: ‘기록 중’ 표시 후 앱에서 클릭·입력합니다. 녹화창이 가리면 접어두기, 잠시 멈추려면 Esc를 사용합니다.
  3. 기록 마치고 검토: 순서·대상·입력값을 읽습니다. 빠진 동작은 경고를 확인하고 보완합니다. 경고를 확인하는 것만으로 누락 동작이 복원되지는 않습니다.
  4. 필요한 단계만 수정: 단계를 두 번 클릭합니다. 대상은 이 단계만 다시 지정, 결과 판단은 완료 기준 지정으로 고칩니다.
  5. ▷ 시험 실행: 앱을 시작 화면으로 다시 준비하고 현재 초안을 시험합니다. 실제 앱을 조작합니다. 결과가 다르면 해당 단계만 고칩니다.
  6. 프로세스 저장: 이름을 입력해 저장하고 채팅의 저장 완료를 확인합니다. 저장 자체는 다시 실행하지 않습니다.
녹화 중에는 실제로 작업합니다. 클릭과 입력은 업무 앱에 적용됩니다. 취소해도 이미 수행한 작업이 되돌아가지는 않습니다. 동영상 파일 대신 재생 가능한 동작 단계를 만듭니다.

마우스를 올려둔 사실만으로 클릭·값 선택을 기록하지 않습니다. 비밀번호나 대상이 불명확한 키 입력은 그대로 저장하지 않습니다. 일부 특수 컨트롤·드래그 등은 직접 보완이 필요할 수 있으므로 초안을 확인하세요.

녹화를 마쳤는데 오류가 나면

편집창을 닫기 전에 최근 녹화 다시 분석 버튼이 보이는지 확인하세요. 보관된 원본으로 단계를 다시 만들며, 앱에 클릭·입력을 보내거나 다시 녹화하지 않습니다. 현재 편집창의 최근 녹화만 다시 분석합니다. 녹화 뒤 직접 고친 단계가 있으면 덮어쓰지 않으므로 필요한 단계만 수정하세요.

‘일부 동작이 빠졌다’는 경고는 검토가 필요하다는 뜻입니다. 경고를 확인하거나 다시 분석해도 애초에 기록되지 않은 동작이 복원되지는 않습니다. 녹화 전에 준비 점검에서 멈췄다면 아직 기록을 시작하지 않은 상태이므로 안내된 원인을 고친 뒤 시작합니다.

대상 지정 문제로 생긴 경고는 관련 단계를 직접 고쳐 문제가 모두 해결되면 해제됩니다. 동작 누락이나 입력값 미확인 같은 다른 경고는 그대로 남습니다. 저장 버튼을 눌렀을 때 남은 검토 사항이 표시되면 그 내용을 확인하세요.

재생 중 이미지를 못 찾은 경우에는 현재 창과 해당 단계의 대상을 확인합니다. 앞서 실행한 동작까지 되풀이하려고 전체 작업을 새로 시작하지 마세요. 이미 보냈거나 전달 여부가 불명확한 입력은 현재 결과부터 확인합니다. 녹화 원본을 다시 분석하는 것과 저장한 작업을 재생하는 것은 별도 동작입니다.

버튼 색상이 달라 재생이 멈추면

같은 실행을 이어가줘. 현재 화면에서 저장한 것과 같은 버튼인지 확인하고, 아직 입력하지 않은 단계만 진행해줘.

이미지 전달을 허용한 연결에서는 모델이 저장된 대상 이미지와 현재 화면을 함께 봅니다. 같은 버튼을 구별한 근거를 제시하면 이번 실행의 해당 단계에서만 그 대상을 사용합니다. 저장한 작업은 그대로 남으며, 앞서 수행한 동작을 다시 누르지 않습니다.

실제 MuMu 시험에서는 버튼 색상 차이를 이 방식으로 복구하고, 저장한 원본을 유지한 채 이어가기와 새 실행을 완료했습니다. 새로 학습해 저장한 이미지로 바꾸는 기능은 아닙니다.

같은 아이콘이 여러 개면 줄 이름·버튼 위치 같은 주변 정보도 확인합니다. 대상이 없거나 실행할 수 없는 상태라면 멈춥니다. 화면이 바뀌었거나 이미 입력했는지 불명확할 때 임의로 반복하지 않습니다.

앞선 단계의 값·상태는 다시 확인합니다. 같은 창에서 모델이 확인한 결과는 화면 전체가 그대로일 때만 이어받으므로 시계·커서·애니메이션이 계속 바뀌는 창에서는 새 화면으로 다시 확인해야 할 수 있습니다. 이전 화면 확인이 다른 창에서 이루어졌다면 현재 창의 그림으로 대신 판단하지 않고 자동 이어가기를 멈춥니다. 이미지 전달을 쓰지 않는 연결에서는 프로세스 편집창에서 해당 단계만 수정할 수 있습니다.

요소를 못 읽으면 같은 창에서 이미지로 지정

  1. 편집창에서 대상을 선택합니다. 조작 가능한 요소 정보가 충분하지 않으면 이미지로 지정할 수 있습니다.
  2. 대상 창의 현재 캡처에서 버튼과 구분되는 주변 내용을 사각형으로 선택합니다.
  3. 실제로 누를 위치를 버튼 안에 지정하고 확정합니다. 현재 창에서 이미지를 다시 찾아 실행합니다.

반복된 실행 버튼: 아이콘만 선택하지 말고 해당 줄의 고유한 이름을 함께 포함하세요. “맨 위 첫 번째 줄”처럼 요청한 구분 기준을 확인합니다. 입력칸은 바뀌는 입력값보다 주변의 고정된 이름이 좋은 기준입니다.

‘Button’이라는 종류가 보이는 것과 실제로 그 버튼을 다시 찾아 조작할 수 있는 것은 다릅니다. 대상을 특정할 수 없을 때 다른 부모 영역을 임의로 누르지 않습니다. 캡처가 실패하면 실제 오류 원인을 확인하며 같은 F8·캡처 요청만 반복하지 않도록 되어 있습니다.

같은 작업에서 값만 바꾸기

저장한 ‘반복 조회’를 이번에는 조건 N으로 실행해줘. 저장된 기본값은 그대로 둬.

입력 단계를 수정할 때 실행할 때 바꿀 값으로 사용을 선택하고 이름을 지정합니다. 다음 실행에는 그 값만 바꿔 말할 수 있습니다.

‘반복 조회’의 조건 입력 기본값을 N으로 바꿔줘. 다른 단계와 이미지 대상은 유지해줘.

기존 작업을 편집창으로 다시 열면 같은 작업의 새 버전으로 저장합니다. 전체를 다시 녹화할 필요가 없습니다. 다른 곳에서 먼저 수정한 버전이 있으면 덮어쓰기 전에 알려줍니다. “이전 버전으로 되돌려줘”도 가능합니다.

문자·숫자·정수·날짜·참/거짓·선택지·목록을 구분합니다. 진행 중인 실행은 시작 당시 버전과 입력값을 유지합니다. 목록 반복은 최대 100개 항목, 펼친 실행 최대 300단계이며 중첩·무한 반복은 지원하지 않습니다.

결과를 확인하는 세 가지 방법

확인 방법무엇을 확인하나요?
요소 상태입력값·선택 상태·완료 문구 등 정한 조건을 실제 화면 요소에서 읽습니다.
모델의 화면 판단이미지 전달을 허용한 연결에서 새 결과 화면을 읽습니다. 모델이 화면 근거로 판단한 결과로 구분합니다.
사람의 직접 확인사람 확인으로 지정한 단계는 PC의 확인창에서 직접 결과를 확인합니다. 모델 판단으로 대신하지 않습니다.

버튼 클릭 전달만으로 조회 완료나 저장 성공을 판단하지 않습니다. 단순히 화면 색이 바뀌거나 줄무늬가 보인다는 사실도 업무 성공의 충분한 근거가 아닙니다.

기본은 텍스트 전달입니다. 로컬 이미지 저장·매칭은 가능하지만 모델에 이미지를 자동 전송하지 않습니다. 이미지가 필요하면 모델의 지원 여부를 확인하고 화면 이미지 사용을 요청하세요. MCP 자체는 외부 LLM API를 별도로 호출하지 않으며 전달된 내용의 처리 위치는 연결한 채팅 앱·LLM 설정을 따릅니다.

빠르게 반복하고, 멈춘 지점부터 이어가기

한 번 검증된 경로는 재사용합니다. 다음 실행에서도 이번 입력값과 완료 조건은 확인합니다. 고정된 몇 초 대기 대신 결과 요소가 나타나면 진행하도록 만들면 준비됐을 때 바로 이어갑니다. 프로그램의 로딩·서버 처리 시간은 남습니다.

방금 멈춘 실행을 이어가줘. 이미 수행한 동작은 반복하지 말고, 현재 결과를 확인해서 필요한 단계부터 진행해줘.

원래 버전·입력값·완료 기록으로 이어갑니다. 이미 보냈거나 전달이 불명확한 입력은 결과부터 확인합니다. 새 실행은 앞의 동작도 다시 실행할 수 있으므로 같은 실행 이어가기라고 요청하세요.

종료까지 부탁하면 실제 창과 남은 저장 확인창을 확인합니다. “저장하지 않고 닫아줘”처럼 원하는 처리 방법을 함께 알려주세요. 자동화 중단은 앱 강제 종료가 아닙니다.

다음에도 쉽게 부르려면 스킬로 내보내기

검증한 ‘반복 조회’를 스킬로 내보내줘. 실행할 때 조건값을 바꿀 수 있게 안내해줘.

작업·고정 버전·입력값과 호출 방법을 담은 작은 SKILL.md가 만들어집니다. 임의 실행 코드를 생성하거나 개인 스킬 설정을 자동으로 바꾸지 않습니다. 다른 PC에도 참조하는 작업과 대상 프로그램이 준비되어 있어야 합니다.

문제가 생기면 전체를 다시 만들지 마세요

상황확인할 내용
같은 이름의 창이 여러 개현재 창 목록에서 사용할 창을 선택합니다. 오래된 창 번호를 다시 입력하지 않습니다.
