COMPUTER USE MCP · 0.10.0

한 단계씩 알려주고
다시 실행하는 화면 작업

요소를 직접 고르고, 클릭·입력·대기를 순서대로 쌓아 프로세스로 저장합니다. 코드를 쓰거나 JSON 파일을 편집하지 않아도 됩니다.

1. 채팅에서 시작하세요

먼저 사용할 프로그램을 열고, 채팅에서 다음처럼 요청하세요. 처음 쓰는 프로그램이면 설정 화면에 실행파일을 등록해야 합니다.

지금 열린 프로그램으로 반복 작업을 만들고 싶어. 프로세스 편집 창을 열어줘. 요소는 내가 직접 선택할게.

편집 창이 보인 뒤 진행합니다. 같은 요청을 반복해 여러 창을 열 필요가 없습니다. 세션 시간이 끝나면 편집도 종료되므로, 긴 작업은 시작할 때 필요한 시간을 알려주세요.

2. 요소와 동작을 추가하세요

  1. 편집 창에서 대상 프로그램을 선택합니다.
  2. 요소 선택을 누릅니다. 선택 도우미에서 3초 후 위치 선택을 누르고 대상에 마우스를 올리거나, 대상 위에서 F8을 누릅니다.
  3. 요소 이름·종류가 맞는지 확인하고 이 요소로 선택을 누릅니다. 돌아온 편집 창에서 선택한 요소를 확인합니다.
  4. 동작을 고릅니다. 글자 입력이면 넣을 내용을, 목록 선택이면 고를 항목을 입력합니다.
  5. 클릭·키보드 동작은 동작 뒤 확인할 요소와 예상 결과도 정합니다. 예를 들어 조회 버튼 뒤 결과 입력칸에 “완료”가 나오는지 확인하도록 지정합니다.
  6. 단계 추가를 누릅니다. 오른쪽 목록에서 프로그램·요소·동작·입력값·확인 조건을 확인합니다.

작성 중에는 업무 프로그램을 자동으로 누르지 않습니다. 다음 화면의 요소를 가르치려면 직접 프로그램을 다음 화면으로 이동한 뒤 다시 선택하세요. 마우스의 모든 움직임을 몰래 기록하는 녹화 기능은 아닙니다.

잘못 추가한 단계는 삭제 후 다시 추가하고, 위·아래 이동으로 순서를 바꿀 수 있습니다. 한 프로세스는 최대 30단계입니다.

3. 기다림과 화면 확인을 넣으세요

단계언제 쓰나요?실행 결과
요소가 나타날 때까지 대기다음 화면에 특정 버튼이나 입력칸이 생길 때가르친 요소가 고유하게 나타나는지 최대 60초 안에서 확인합니다. 읽기 실패는 “없음”으로 넘기지 않습니다.
고정 대기잠깐 기다린 뒤 다음 작업을 해야 할 때지정한 0~60초를 기다립니다. 시간이 지난 것만으로 화면 준비 완료를 보장하지는 않습니다.
화면 이미지 확인차트·배치·작업 결과를 눈으로 확인하고 싶을 때연결한 창의 이미지를 채팅으로 전달하고 일시정지합니다. 사용자가 확인한 뒤 이어갑니다.

화면 이미지 확인은 그림 버튼을 자동으로 학습하거나 비교하는 기능과 다릅니다. 이미지가 찍혔다고 작업 성공으로 표시하지 않습니다. 대상 창이 최소화되거나 다른 창 뒤에 있으면 맨 앞으로 가져온 뒤 다시 화면을 확인합니다. 다른 앱의 화면이 섞이지 않도록 자동으로 캡처하지 않습니다. 이미지는 프로세스 파일에 저장하지 않지만, 연결한 MCP 클라이언트의 대화에는 전달됩니다.

4. 이름을 붙여 저장하고 실행하세요

전체 순서를 확인한 뒤 프로세스 이름을 적고 저장을 누릅니다. 채팅에서 저장 완료가 확인되면 다음처럼 요청할 수 있습니다.

저장한 “조회 결과 확인” 프로세스를 실행해줘. 중간에 화면 확인 단계가 나오면 나에게 보여주고 기다려줘.

화면 확인 후에는 “화면 확인했어. 이어서 진행해줘.”라고 요청하세요. 완료한 입력을 무작정 다시 실행하지 않고, 현재 상태를 다시 확인합니다.

프로그램과 MCP를 다시 열어도 저장한 프로세스를 조회할 수 있습니다. “저장한 프로세스 목록을 보여줘”, “이 프로세스를 복사해서 편집 창으로 열어줘”라고 요청하세요. 복사 편집은 새 작업으로 저장해 원본을 보존합니다.

프로세스에는 직접 작성한 입력 내용과 요소를 찾는 기준이 저장됩니다. 비밀번호·OTP는 저장하지 마세요. 종료가 필요한 작업은 실행 후 종료·저장 팝업을 처리하고 별도의 종료 확인 기능으로 실제 창/프로세스 종료를 확인하도록 요청하세요.

선택했는데 저장할 수 없는 경우

프로그램마다 Windows에 제공하는 요소 정보가 다릅니다. 일반 버튼·입력칸은 잘 제공하는 경우가 많지만, 게임·에뮬레이터·자체 그림 화면은 버튼이 보여도 요소 정보가 없을 수 있습니다.

이번 버전은 Driver의 실제 위치 정보 형식과 누락된 자동화 ID를 보완해, 동일한 이름·종류·위치로 교차 확인되는 요소를 저장합니다. 그러나 프로그램이 버튼 정보를 아예 제공하지 않는 경우에는 picker_controls_not_exposed 등 구체적인 원인을 안내하며 저장 성공으로 표시하지 않습니다. F8을 반복해도 이 문제는 해결되지 않습니다.

현재 프로세스의 자동 클릭·입력은 UIA 요소를 대상으로 합니다. 그림으로만 제공되는 버튼의 이미지 학습·자동 재탐색은 이번 버전에 포함되지 않았습니다. 이미지 확인 단계와 그림 버튼 학습을 혼동하지 마세요.

새 버전 적용

새 배포 ZIP 전체를 새 폴더에 압축 해제하세요. INSTALL.md를 채팅에 첨부하고 “기존 설정과 Driver, 프로그램, 저장한 작업과 학습 요소를 유지하고 이 버전으로 연결을 갱신해줘”라고 요청합니다. 연결을 다시 연 뒤 버전 0.10.0과 computer_process_editor가 보여야 합니다.

프로세스 편집 실행파일은 MCP가 필요할 때 자동으로 엽니다. 사용자가 직접 실행하거나 Python 명령을 입력할 필요가 없습니다.
