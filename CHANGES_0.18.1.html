캡처 자료는 모으고, 사용이 끝난 임시파일은 정리합니다

2026-10-18 · 0.18.1 · 별도 설정 없이 기존과 같이 녹화하고 저장하세요.

실행할 때 필요한 이미지는 계속 유지합니다

재생에 필요한 기준 이미지는 저장한 작업 안에 별도로 포함됩니다. 녹화 원본은 작업을 만들거나 보완할 때 사용하는 복구용 자료입니다. 실행 가능한 완성 작업에 반영된 원본만 저장 후 7일간 보관한 뒤 정리합니다.

저장 실패·보완 중인 원본과 초안, 저장 작업의 이미지·이전 버전·스킬, Excel·PPT 등 실제 업무 결과는 자동 삭제하지 않습니다. 과거 버전에서 남은 미확인 자료도 유지합니다.

자료가 뒤섞이지 않도록 보관합니다

설정된 기록 폴더의 runs/실행 ID/ 아래에 임시 이미지와 녹화 자료를 모으고 업무 이름과 저장 작업 ID를 기록합니다. 같은 업무도 실행별로 분리됩니다. 채팅에서 “현재 작업의 이미지 저장 위치와 정리 상태를 알려줘”라고 요청할 수 있습니다.

사용이 끝난 자료만 정리합니다

임시 이미지는 사용 후 제거합니다. 종료가 확인된 잔여 임시파일과 보관 기간이 지난 원본은 MCP 시작·새 세션 시작·종료 때 짧게 나누어 정리합니다. MCP를 사용하지 않는 동안 별도 정리 프로그램이 실행되지는 않습니다.

도우미가 열려 있거나 파일이 잠겼다면 보존합니다. 소유를 확인할 수 없거나 내용이 바뀐 파일, 연결 경로는 정리 대상에서 제외합니다.

검증한 범위

보관·정리 관련 집중 검사 77건 중 76건을 통과했습니다. Windows 권한이 필요한 실제 심볼릭 링크 생성 1건은 제외했으며, 연결 경로 속성 검사와 실제 하드링크 보호는 통과했습니다. 합성 녹화를 실제 저장 작업으로 변환한 뒤 7일 경과를 재현하여 원본만 정리되고 저장 작업의 바이트와 재생 이미지가 그대로 남는 것을 확인했습니다.

기존 사용자의 녹화 원본은 삭제하지 않았습니다. 이번 파일 보관 수정으로 Chrome 클릭이나 전체 앱 녹화·재생 검사를 반복하지 않았습니다. 검증 상세
