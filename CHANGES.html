0.18.6 팝업·중첩 메뉴 녹화와 재생 개선

  • 관련 팝업을 관찰할 때 메인 창을 활성화해 목록을 닫던 문제와 재개 시 메인·팝업 연결이 섞이는 문제를 개선했습니다.
  • 같은 이름·클래스의 중첩 메뉴를 별도로 기록하고 실제 소유 관계와 다음 동작을 구분합니다. 빠른 클릭의 자료가 없으면 보완 단계로 남깁니다.
  • Driver가 정확한 팝업 HWND를 누락한 경우에만 소유 관계를 검증한 캡처·메시지 입력 보조 경로를 사용합니다. 권한·중단·동작 횟수 검사는 유지합니다.
  • 제한된 호버 색상 및 창 테두리 차이를 처리합니다. 이미지 기준을 일괄 낮추거나 중복 후보를 임의 선택하지 않습니다.
  • 확인된 업무 조건·대상·문맥은 유지하면서 대상 밖 변화에 의한 확인 반복을 줄이고, 확인된 입력은 재개 시 반복하지 않습니다.
  • MSAA 읽기 실패의 원인을 분리하고 제한된 읽기 복구를 추가했습니다. 실제 로드된 코드 식별 정보를 기록합니다.

기존 설정·녹화 원본을 다시 만들 필요는 없습니다. 다만 원본에 이미지가 없거나 후보가 모호하면 해당 단계 보완이 필요할 수 있습니다.
