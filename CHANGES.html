0.18.7 팝업·녹화·검증 개선

  • 녹화 전 사람 확인·모델 화면 판정·자동 조건을 구분합니다. 모델 이미지 연결을 먼저 확인하고, 기존 필수 사람 확인이나 사용자가 수정한 확인 문구는 보존합니다.
  • 주 창과 관련 팝업을 구분해 비활성 관찰하고, 같은 실행에서 팝업 증명을 다시 구성합니다. 전달이 확인된 입력으로 팝업이 닫힌 경우에만 사전 연결한 owner에서 결과를 확인합니다.
  • Driver의 정확한 팝업 누락 오류에만 제한된 캡처·메시지 입력 보조 경로를 사용합니다. 보조 클릭 직전에 이미지를 다시 확인하고, 권한 거부·전송 불명·대상 변경은 재클릭하지 않습니다. 보조 backend는 로그에 별도로 남깁니다.
  • 같은 이름·클래스의 메뉴와 같은 HWND의 재표시를 구분해 기록합니다. 빠른 클릭의 사전 이미지가 없으면 동작을 버리지 않고 보완 단계로 남깁니다.
  • 반복 행의 scope도 전체 화면에서 유일하게 일치해야 합니다. 빈 셀의 첫 후보를 임의로 선택하지 않습니다. 고유한 행 이름 등 구별 문맥을 사용합니다.
  • 명시한 좁은 시계 영역 외의 변화는 계속 검사합니다. 이전 확인 증거가 있다고 다른 업무 조건 변화를 무시하지 않습니다. 모든 과거 업무 조건을 자동 추적하는 기능은 아닙니다.
  • 밝은 호버 배경·테두리 보정을 개선하고 글자 변경·비활성·가림·중복 후보는 거부합니다. 전체 임계값은 낮추지 않습니다.
  • MSAA의 HWND 변화·native 조회 실패·provider 오류·잘못된 응답을 구분하고, 확인창의 현재 상태와 재표시 처리를 보완합니다.

업데이트

Driver 포함 ZIP 전체를 새 폴더에 풀고 INSTALL.md로 연결을 갱신하세요. 기존 설정·저장 작업·녹화 원본은 유지합니다. 연결을 다시 시작한 뒤 computer_status.version이 0.18.7인지 확인하세요. 오래된 MCP 프로세스는 파일을 복사하는 것만으로 갱신되지 않습니다.

기존 녹화를 자동 수정하거나 사람 확인을 자동 승인하지 않습니다. 필요한 조건·대상 변경은 편집창에서 확인 후 새 revision으로 저장합니다.
