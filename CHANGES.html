0.18.8 중첩 메뉴 재생 수정

Export to excel 같은 중첩 메뉴가 열렸는데도 전면 창을 확인하지 못해 재생이 멈추던 문제를 수정했습니다.

  • 클릭 전달이 확인된 뒤 전면 창 확인에 실패한 경우에 한해, 작업에 선언된 이미 열린 하위 메뉴를 읽기 전용으로 연결합니다. 클릭을 반복하지 않습니다.
  • 별도의 복구 요청 없이 같은 실행 요청에서 저장된 다음 화면 확인 단계로 이어집니다. 기존 완료 조건과 모델 화면 판정·필수 사람 확인을 그대로 유지합니다.
  • 기존 22단계 작업과 revision 1을 수정 없이 재사용했습니다. 시험 앱을 새 프로세스로 다시 시작한 경우를 포함해 두 차례 전체 재생과 XLSX 생성을 확인했습니다.

업데이트

Driver 포함 ZIP 전체를 새 폴더에 풀고 INSTALL.md로 연결을 갱신하세요. 기존 설정·저장 작업·녹화 원본은 유지합니다. 연결을 다시 시작한 뒤 computer_status.version이 0.18.8인지 확인하세요. 오래된 MCP 프로세스는 파일을 복사하는 것만으로 갱신되지 않습니다.

이번 수정 때문에 다시 녹화할 필요는 없습니다. 기존 확인 단계를 자동 승인하지 않으며, 필요한 조건·대상 변경은 편집창에서 확인 후 새 revision으로 저장합니다.
