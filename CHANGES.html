COMPUTER USE MCP · 0.19.0

로컬 녹화 편집·입력값·스킬 미리보기

기존 재생 엔진을 유지하면서 작성과 반복 실행의 입력 흐름을 정리했습니다.

0.19.0 시험 앱의 녹화·저장·앱 재시작 후 재생·Excel 결과를 확인했습니다. 적용 범위와 제한은 검증 안내를 확인하고, 배포 파일과 실제 게시 상태는 GitHub Releases에서 확인하세요.

반영한 기능

  • 편집창의 단계 / 입력값 / 스킬 보기 탭, 되돌리기·다시 적용, 저장 후 계속 편집과 미저장 변경 안내.
  • 입력값의 형식·필수 여부·기본값·사용 단계 관리. 시험과 저장 작업 실행의 로컬 입력폼, 같은 실행 재개의 원래 값 유지.
  • 저장된 revision만 스킬로 미리 보고 정확히 같은 파일을 내보내기. 자동 설치 없음.
  • 기존 업무명 형태의 작업 ID를 로컬 별칭으로 연결하여 원본 작업을 바꾸지 않고 공개 응답과 스킬 본문에서 업무 식별자를 제외.
  • 기본 로컬 정책에서 화면·업무 텍스트·입력값·상세 오류는 이 PC의 창에서 표시. 채팅에는 상태와 불투명한 ID, 진행 개수만 반환.
  • 편집창의 배율과 레이아웃을 점검하고 로컬 입력·결과창의 소유 관계와 종료 처리를 유지.

기존 녹화·재생과 속도

기존 녹화 원본·재생 이미지·revision을 자동 변환하지 않습니다. 창·팝업 연결, 이미지 유일성, 입력 전달·결과 확인, 같은 실행 재개 경로를 유지합니다. 사람 확인을 자동 승인하거나 불명확한 입력을 반복하지 않습니다.

편집 분석과 스킬 생성은 재생 단계마다 실행하지 않습니다. 가상 화면 기반 120회 비교에서 입력·관찰 횟수는 같았으며 최초 실행 중앙값 +2.73%, 반복 실행 +0.45%였습니다. 실제 운영 프로그램·Driver·모델의 성능 검증이나 10초 실행 보장은 아닙니다.

업데이트 시 달라지는 정책

정책 설정이 없던 기존 설정도 data_policy=local로 처리합니다. 모델 화면 판정 단계가 들어 있는 기존 작업은 첫 입력 전에 제한을 안내합니다. 편집창에서 자동 조건 또는 직접 확인으로 새 revision을 저장하세요.

관리자가 명시한 connected는 기존 사내 클라이언트의 직접 조작·모델 화면 판정 경로를 유지합니다. connected에서는 로컬 전용 보장이 적용되지 않습니다. 기존 사람 승인·실행 스냅샷은 변경하지 않습니다.

새 ZIP 전체를 별도 폴더에 풀고 기존 설정과 작업을 유지해 연결을 갱신합니다. 파일만 교체하지 말고 MCP 연결을 다시 시작하세요.

검증 상태

회귀 검사와 네이티브 도우미 빌드를 확인했고, 시험 앱에서 실제 녹화·입력값 분리·저장·스킬 미리보기/내보내기를 진행했습니다. 시험 앱을 새 프로세스로 다시 시작한 뒤 저장한 두 단계를 다른 입력값으로 재생했고, 2/2 완료와 새 XLSX의 실제 셀 내용을 확인했습니다. 내보내기는 한 번 수행됐습니다. 확인한 범위와 남은 항목을 구분해 기록합니다.
