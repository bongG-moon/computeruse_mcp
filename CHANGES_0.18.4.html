Computer Use MCP 0.18.4

시작 창을 출발점으로 삼고 단계별 업무 창과 관련 팝업을 따라가도록 개선했습니다.

창과 녹화

  • 최상위 창 목록에 없는 업무 자식 창도 실제 owner·parent 관계를 따라 확인합니다. 다른 프로세스와 무관한 창은 연결하지 않습니다.
  • 중첩 팝업을 가까운 부모 창에 연결하여 녹화·저장하고, 원래 업무 창으로 돌아오는 단계를 유지합니다.
  • 자동 식별된 팝업은 단계마다 다시 확인합니다. 사용자가 명시한 창 지정은 임의로 덮어쓰지 않습니다.
  • 진행 상태에 대상 창 번호·관련 창 여부·동작을 제공합니다.

이미지와 복구

  • 4px 이내의 작은 캡처 크기 차이는 테두리 차이일 수 있어 원본 배율을 우선합니다. DPI 변화가 입증되었다는 의미는 아닙니다.
  • RGB 기준 미달 시 주변 윤곽으로 최대 3개의 확인용 후보를 제공합니다. 자동 클릭 기준을 낮추지 않으며, 같은 캡처임이 확인된 경우에만 현재 화면의 후보로 제공합니다.
  • 유사도·기준·크기 차이를 안내하고 화면이 달라졌다고 단정하지 않습니다.
  • 편집창에서 실패한 단계만 다시 지정하도록 안내합니다. 저장 완료와 실제 재생 성공을 구분합니다.

검증 범위

창 관계·중첩 저장·재생·이어가기 및 이미지 복구에 대한 회귀 테스트를 실행했습니다. 합성 화면의 테두리 차이, 강조 색상·입력값 변경, 중복 후보와 오래된 캡처 차단을 검사했으며 C# 도구 컴파일과 네이티브 이미지 검사도 수행했습니다. 배포 도구는 런타임·실행기·이미지 매칭과 배포 명세/체크섬을 검사합니다.

실제 사내 SmartFX 화면에서의 녹화·재생은 미검증입니다. 모의 창 관계와 합성 이미지 검사는 운영환경 성공을 보장하지 않습니다. 기존 녹화와 프로그램 설정을 자동 수정하지 않습니다.
