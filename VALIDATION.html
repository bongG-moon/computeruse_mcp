0.18.7 검증 범위

팝업·확인 정책·녹화·시각 복구·MSAA·결과 파일 관련 25개 모듈의 710개 테스트가 통과했습니다. 실패·오류·건너뜀은 0개입니다. 네이티브 도구를 다시 빌드하고 실제 이미지 backend 및 모듈 로드를 검사했습니다.

  • 실제 이미지 비교기로 반복 빈 셀의 모호성 거부와 고유 행 문맥의 유일한 일치를 확인했습니다.
  • 렌더링한 시험 화면에서 시계만 변한 경우와 MES·Family 업무 조건이 변한 경우를 구분했습니다. 작은 시계 예외의 범위·겹침·증거 누락도 검사했습니다.
  • 실제 offscreen HWND 시험에서 동명 메뉴, 중첩 owner, 같은 HWND의 숨김·재표시, 빠른 클릭 보완 기록을 확인했습니다. 사용자 입력 hook을 통한 전체 녹화·재생 시험과는 다릅니다.
  • Guard 보조 입력의 권한·범위·전송 불명·이미지 재검증은 모의 OS/Driver 계약 시험으로 확인했습니다. 실제 운영 팝업 메시지 입력의 성공을 뜻하지 않습니다.
  • 별도 화면 제어 도구로 시험 앱에서 N·Hybrid 선택 → 조회 → 우클릭 → Export to excel → Active sheet를 수행했고 새 XLSX의 5개 데이터 행을 확인했습니다. 이번 제품 MCP 수정본의 신규 녹화→저장→재생으로 생성한 결과는 아닙니다.

남은 제한

운영 SmartFX 전체 재생, 제공되지 않은 원본 호버 이미지, 간헐적 MSAA 실패의 실제 원인은 아직 직접 검증하지 못했습니다. 진한 선택색·다크 테마·가려진 글자와 확인창의 다른 창에 의한 가림은 추가 실측이 필요합니다.

직전 확인 증거는 그 조건만 증명합니다. 모든 과거 업무 조건을 자동 추적하는 기능은 없으며, 필요한 조건들을 완료 조건과 근거에 함께 포함해야 합니다. 시험 실행 시간은 운영 업무의 성능 측정 결과가 아닙니다.

0.18.6의 22단계 녹화·재생 결과는 이전 버전 이력입니다. 이를 0.18.7의 새 전체 재생 성공 증거로 사용하지 않았습니다. 기존 녹화·revision·업무 데이터·승인 기록은 유지합니다.
