COMPUTER USE MCP · 0.19.2 · 2026-10-29

확인한 결과와 남은 검증

이번 인식 개선의 검사와 이전 실제 화면 및 파일 검증을 구분합니다.

0.19.2는 SmartFX와 FXMenuAgent의 업무 창 연결, 드롭다운 및 메뉴 녹화, 읽기 전용 접근성 진단을 보완합니다. 기존 녹화와 로컬 데이터 정책을 유지하며, 적용 범위와 남은 제한은 검증 기록에서 확인하세요. 실제 게시 상태와 배포 파일은 GitHub Release를 기준으로 합니다.

0.19.2에 포함한 SmartFX 및 FXMenuAgent 소스 검증

2026-10-28에 검토한 개선입니다. 아래 수치는 해당 소스와 시험 fixture의 결과이며, 운영 사내 앱의 전체 동작 성공을 뜻하지 않습니다. 새 ZIP으로 연결을 갱신하고 MCP를 다시 시작해야 적용됩니다.

  • 승인된 현재 EXE와 실제 관찰된 업무 영역, 툴바, 조건, 표 및 속성 편집기 메타데이터로 처리 경로를 구분합니다. 정적 필드명은 AutomationId로 추정하지 않습니다.
  • 임베디드 업무 Form의 owner/parent 경로와 숨겨진 동일 팝업 HWND의 재표시를 확인합니다. 실제 자식 Panel/ListBox는 팝업 후보와 구분합니다. Driver 누락, 모달, 교체, 중복 후보는 별도로 진단합니다.
  • 메뉴와 목록 클릭은 최신 Driver 기능 및 안정적인 선택자가 확인되면 요소 단계로 보존합니다. 기존 녹화, revision, 승인과 local 데이터 보호 정책은 유지합니다.

최종 영향권 회귀 342개 통과, 실제 offscreen WinForms HWND 시험 12/12 통과, 관찰 중 전경 변경 0회였습니다. source helper와 자체 fixture를 사용한 결과로 실제 사내 앱 입력 및 전체 녹화 재생 성공을 뜻하지 않습니다.

600개 합성 요소에서 200개를 반환하는 메모리 내 요소 정리 시험을 10회 수행했습니다. 중앙값은 공통 24.405ms, SmartFX 8.960ms, FXMenuAgent 8.947ms였고 각 Driver 호출은 1회였습니다. 추가 전체 트리 진단이나 모델 호출은 없습니다. 실제 업무 앱의 총 실행 시간을 측정한 결과가 아닙니다.

독립 업무 창 전환의 녹화 중 자동 편입, 가상 표 셀의 Realize/ScrollItem 실행, 임의 PropertyGrid 편집 및 운영환경 전체 재생과 Excel 결과 확인은 남은 범위입니다. 제목 없는 사용자 정의 808 모달에 구별 근거가 없으면 클래스만으로 종류를 확정할 수 없습니다.

실행 방식과 제한 / Provider 및 Driver 진단. 재현 소스는 test_smartfx_profiles.py, test_combo_popup.py, test_recorded_menu_semantics.py, tools/check_combo_popup_native.py, tools/benchmark_smartfx_profiles.py에 포함합니다. 실제 업무 캡처와 원본 녹화는 공개 소스에 넣지 않습니다.

과거 기록 · 0.19.0 실제 화면 시험

아래는 2026-10-25에 수행한 0.19.0 검증이며, 0.19.2에서 새로 재생한 결과가 아닙니다. 당시 영향 경로 검사는 381개 중 380개 통과·하드링크 권한 제한으로 1개 제외, 배율·미리보기 추가 검사 9개 통과였습니다.

  • 외부 접속 없는 Windows 시험 앱에서 실제 입력 hook을 사용해 두 단계(값 입력·체크 상태 변경)를 녹화했습니다.
  • 보이는 편집창에서 입력 단계를 실행 변수에 연결하고 revision 1로 저장했습니다.
  • 로컬 스킬 미리보기와 파일 내보내기를 확인했습니다.

시험 앱의 완전 종료를 확인하고 새 프로세스로 다시 시작한 뒤, 저장 작업을 로컬 입력폼의 다른 값으로 재생했습니다. 두 단계 모두 verified였고, 새 XLSX의 실제 셀에서 변경한 입력값과 Family 값을 확인했습니다. 해당 실행의 내보내기는 1회였습니다. Family 드롭다운을 새로 녹화·선택한 시험이 아니라 값 입력과 체크 상태 변경 두 단계의 검증입니다.

실제 Driver를 사용한 이 두 단계 재생의 active 시간은 12,320.35ms(동작 12,288.6ms, 창 연결 29.81ms)였습니다. 사용자 입력 대기는 제외했으며 기존 버전과 통제한 실제 앱 속도 비교는 아닙니다. 운영 업무 10초 완료를 보장하지 않습니다.

기존 재생 검증과 구분

이 절은 이전 안내의 검증 링크를 유지합니다. ClickOnce 관련 과거 시험은 프로그램 연결 안내의 범위를 참고하며, 이번 로컬 작성 경로의 시험과 구분합니다.

이전 0.18.8 및 이후 소스 검증에서는 중첩 팝업의 기존 22단계 작업을 재사용해 N·Hybrid 선택→조회→Export 메뉴→Active sheet와 XLSX 데이터 5행을 확인한 기록이 있습니다. 그 결과는 0.19.2의 실제 운영 앱 재생 검증을 대신하지 않습니다.

운영 SmartFX, 모든 앱·테마·DPI·다중 모니터의 동작은 별도로 확인해야 합니다. 모델 화면 판정만 통과한 경우와 실제 파일 생성·내용까지 확인한 경우를 구분합니다.

외부 전송에 대한 확인 범위

새 작성 기능에는 외부 모델 API·원격 OCR·업로드 경로가 없습니다. 로컬 정책의 공개 MCP 응답은 허용한 상태·식별자·개수와 제한된 제품 진단 정보만 반환합니다. 0.19.1에서 허용한 진단 정보는 도구 구성·고정 도우미 파일명·존재 여부·버전이며 업무 내용·내부 경로·상세 Driver 오류는 제외합니다. 스킬은 업무 값·이미지·내부 경로 없이 고정된 작업 버전을 호출합니다.

사용자가 다른 도구로 파일을 읽거나 채팅에 직접 입력한 내용, 업무 앱 자체의 네트워크 통신은 이 정책의 제어 범위 밖입니다. 회사 밖 통신 전체의 차단을 검증한 결과는 아닙니다.

오류가 나면 전달할 내용

제품 버전, 중단한 단계 번호, 오류 코드, 입력 전송 여부, 같은 실행 재개 여부를 알려주세요. 로컬 상세 오류에 업무 정보가 있다면 반출 정책에 맞게 가린 요약만 전달합니다. 원본 녹화·이미지·비밀번호·내부 주소를 무조건 채팅에 올리지 않습니다.
