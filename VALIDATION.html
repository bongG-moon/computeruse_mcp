COMPUTER USE MCP · 0.19.1 · 2026-10-28

확인한 결과와 남은 검증

이번 오류 수정의 검사와 이전 실제 화면·파일 검증을 구분합니다.

0.19.1은 로컬 설치 진단과 저장 직후 시험 실행의 팝업 연결 오류를 수정합니다. 새 검증과 0.19.0의 과거 시험 결과는 검증 범위에서 구분합니다. 배포 파일과 실제 게시 상태는 GitHub Releases에서 확인하세요.

최종 통합 검사

0.19.1 소스에서 설치·로컬 응답·편집·창 연결·패키징·배포 도구 검사를 함께 실행했습니다. 292개 중 291개 통과, 1개 제외였습니다. 아래 76개·192개 결과는 해당 경로별 검사 기록이며 합산하지 않습니다.

0.19.1 설치 진단 검사

범위확인 결과
설치 진단·로컬 응답·설치 계약76개 통과. 새 회귀 검사 11개 포함. 제한된 제품 진단 정보만 허용하고, 필수 진단 정보가 없으면 정상으로 처리하지 않음.
실제 MCP stdio 연결 비교게시된 0.19.0은 local에서 도구 누락 오류를 재현하고 connected에서 통과. 수정 소스는 local·connected 모두 통과하며 각각 기본 도구 12개 확인.
격리된 설치 prepare → applyexport-only 폴더에서 실제 Driver 버전 검사와 MCP 연결 통과. 내보낸 설정은 data_policy=local, tool_profile=simple 유지.

사용자 클라이언트 등록·운영 설정 변경·앱 실행 없이 확인했습니다. 시험 실행기는 Python과 서버를 직접 선택했으므로 UAC 연결 경로와 다른 PC의 설치 완료까지 검증한 것은 아닙니다.

0.19.1 저장 직후 시험 실행 검사

범위확인 결과
관련 회귀 검사192개 중 191개 통과, 1개 제외. 새 대상·창 수명 검사 7개 포함.
저장 → 시험 → 같은 실행 재개닫힌 녹화 팝업이 시작 대상에서 제외되고 저장 내용이 바뀌지 않는 것을 확인. 닫힌 기본 창은 재생·입력 호출 전에 안내하고 중지.
실제 Win32 창 수명과 재생 엔진숨김 창을 실제 생성·종료하고 이전 Window no longer exists 오류를 재현. 수정 후 새 팝업 탐색과 2/2 시험 단계, 시험 입력 1회 확인.

Win32 창의 존재 확인과 실제 WorkflowRunner를 사용했지만, 팝업 탐색 화면과 입력 엔진은 시험 대역입니다. 실제 운영 PC의 업무 앱 재생이나 UIA를 통한 업무 입력은 이번에 새로 수행하지 않았습니다. 최종 배포 ZIP·명세·원격 자산 검증은 배포 절차에서 별도로 다룹니다.

과거 기록 · 0.19.0 실제 화면 시험

아래는 2026-10-25에 수행한 0.19.0 검증이며, 0.19.1에서 새로 재생한 결과가 아닙니다. 당시 영향 경로 검사는 381개 중 380개 통과·하드링크 권한 제한으로 1개 제외, 배율·미리보기 추가 검사 9개 통과였습니다.

  • 외부 접속 없는 Windows 시험 앱에서 실제 입력 hook을 사용해 두 단계(값 입력·체크 상태 변경)를 녹화했습니다.
  • 보이는 편집창에서 입력 단계를 실행 변수에 연결하고 revision 1로 저장했습니다.
  • 로컬 스킬 미리보기와 파일 내보내기를 확인했습니다.

시험 앱의 완전 종료를 확인하고 새 프로세스로 다시 시작한 뒤, 저장 작업을 로컬 입력폼의 다른 값으로 재생했습니다. 두 단계 모두 verified였고, 새 XLSX의 실제 셀에서 변경한 입력값과 Family 값을 확인했습니다. 해당 실행의 내보내기는 1회였습니다. Family 드롭다운을 새로 녹화·선택한 시험이 아니라 값 입력과 체크 상태 변경 두 단계의 검증입니다.

실제 Driver를 사용한 이 두 단계 재생의 active 시간은 12,320.35ms(동작 12,288.6ms, 창 연결 29.81ms)였습니다. 사용자 입력 대기는 제외했으며 기존 버전과 통제한 실제 앱 속도 비교는 아닙니다. 운영 업무 10초 완료를 보장하지 않습니다.

기존 재생 검증과 구분

이 절은 이전 안내의 검증 링크를 유지합니다. ClickOnce 관련 과거 시험은 프로그램 연결 안내의 범위를 참고하며, 이번 로컬 작성 경로의 시험과 구분합니다.

이전 0.18.8 및 이후 소스 검증에서는 중첩 팝업의 기존 22단계 작업을 재사용해 N·Hybrid 선택→조회→Export 메뉴→Active sheet와 XLSX 데이터 5행을 확인한 기록이 있습니다. 그 결과는 0.19.1의 실제 운영 앱 재생 검증을 대신하지 않습니다.

운영 SmartFX, 모든 앱·테마·DPI·다중 모니터의 동작은 별도로 확인해야 합니다. 모델 화면 판정만 통과한 경우와 실제 파일 생성·내용까지 확인한 경우를 구분합니다.

외부 전송에 대한 확인 범위

새 작성 기능에는 외부 모델 API·원격 OCR·업로드 경로가 없습니다. 로컬 정책의 공개 MCP 응답은 허용한 상태·식별자·개수와 제한된 제품 진단 정보만 반환합니다. 0.19.1에서 허용한 진단 정보는 도구 구성·고정 도우미 파일명·존재 여부·버전이며 업무 내용·내부 경로·상세 Driver 오류는 제외합니다. 스킬은 업무 값·이미지·내부 경로 없이 고정된 작업 버전을 호출합니다.

사용자가 다른 도구로 파일을 읽거나 채팅에 직접 입력한 내용, 업무 앱 자체의 네트워크 통신은 이 정책의 제어 범위 밖입니다. 회사 밖 통신 전체의 차단을 검증한 결과는 아닙니다.

오류가 나면 전달할 내용

제품 버전, 중단한 단계 번호, 오류 코드, 입력 전송 여부, 같은 실행 재개 여부를 알려주세요. 로컬 상세 오류에 업무 정보가 있다면 반출 정책에 맞게 가린 요약만 전달합니다. 원본 녹화·이미지·비밀번호·내부 주소를 무조건 채팅에 올리지 않습니다.
