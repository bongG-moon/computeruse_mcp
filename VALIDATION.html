0.18.8 검증 범위

이번 수정과 관련된 회귀 테스트 131개가 통과했습니다. 배포 관련 테스트는 31개 중 30개가 통과했으며, 실행 환경에서 지원하지 않는 심볼릭 링크 시험 1개를 건너뛰었습니다.

기존 작업의 실제 재생

이번 수정 소스와 번들 Python을 사용해 제품 MCP 도구로 시험 앱의 기존 22단계 작업을 두 차례 끝까지 재생했습니다. 작업 원본과 revision 1은 그대로 유지했으며, 두 번째 실행은 시험 앱을 새 프로세스로 다시 시작한 뒤 진행했습니다.

  • N·Hybrid 선택 → 조회 → 우클릭 → Export to excel → Active sheet를 수행했습니다. 두 실행 모두 조회 1회·내보내기 1회였으며, 생성된 각 XLSX에서 N·Hybrid 조건의 데이터 5행을 확인했습니다.
  • 중첩 하위 메뉴를 여는 요청 안에서 기존 팝업 화면 확인 단계까지 이어졌습니다. 별도의 복구 호출이나 클릭 반복은 없었습니다.
  • 매 실행에서 기존 9개 화면 확인을 모두 유지하고, 모델이 현재 이미지를 보고 판정한 뒤 진행했습니다. 확인을 생략하거나 일괄 승인하지 않았습니다.
  • 최종 기록은 두 실행 모두 22/22단계 완료와 task_verified: true였습니다. 실제 XLSX 파일의 내용도 별도로 검사했습니다.

검증 범위와 남은 제한

이번 결과는 시험 앱에서 기존 저장 작업을 재생한 검증입니다. 운영 SmartFX와 사람이 새로 녹화→저장하는 전체 과정은 이번에 시험하지 않았습니다. Excel 앱은 실행하지 않았으며, 생성된 XLSX 파일의 구조와 데이터 행을 검사했습니다.

화면 판정은 저장된 완료 조건에 대한 모델 판단입니다. 모든 과거 업무 조건을 자동 추적하거나 모든 화면 픽셀의 동일성을 증명하지는 않습니다. 기존 필수 사람 확인도 자동 승인하지 않습니다. 실제 업무 환경의 테마·가림·응답 시간은 별도 확인이 필요합니다.
