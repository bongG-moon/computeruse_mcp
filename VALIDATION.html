0.18.6 검증 범위

로컬 Windows 시험 앱에서 네이티브 녹화기 → 작업 저장 → 22단계 재생 → 새 XLSX 생성까지 확인했습니다. 파일 내부의 5개 Device 행이 모두 MES=N, Family=Hybrid인지 별도로 검사했습니다.

시험 입력은 제어 도구가 전달한 9개 클릭이며 사람의 직접 시연은 아닙니다. 시각 확인 9회와 대상 보완 1회를 포함했고, 중간 MCP 재시작 후 이어가기를 확인했습니다. 무인 재생 성공을 뜻하지 않습니다. Microsoft Excel 앱 자체를 실행한 시험도 아닙니다.

마지막 수정의 관련 회귀 테스트 13개가 통과했습니다. 재생 후 추가한 오른쪽 테두리 보정은 보존된 캡처로 검증했으며 전체 재생을 다시 반복하지 않았습니다.

실제 소유 팝업 PrintWindow 캡처를 확인했습니다. 메시지 입력 보조 경로는 제한 조건 회귀 테스트를 거쳤지만 모든 실제 재생 클릭이 해당 보조 경로를 사용했다고 확인한 것은 아닙니다.

사내 SmartFX 운영환경 전체 재생과 간헐적 MSAA 실패의 실제 원인은 아직 검증하지 못했습니다. 진한 선택색·다크 테마·가려진 글자·비슷한 빈 셀은 추가 보완이 필요할 수 있습니다. 기존 녹화 자료와 revision은 보존합니다.
