현재 검증 범위

MSAA COM을 실제로 제공하는 로컬 Windows 시험 앱에서 독립 HWND가 없는 List 영역 인식과 물리 좌표 일치를 확인했습니다.

자동 테스트는 기존 녹화 이미지 재사용, 이미지 영역 좌표 변환, 후보 중복 거부, 중단 후 이어가기와 입력 반복 방지, 팝업/종료 회귀, 배포 파일 구성을 검사합니다.

실제 사내 SmartFX와 Automation Anywhere에서 사용한 제공자는 직접 확인하지 못했습니다. MSAA 제공자가 없거나 캡처 좌표계가 다르거나 기존 이미지가 현재 목록과 다르면 실행을 중단합니다. 이미지가 원본에 없었던 단계는 자동 복원할 수 없습니다.

새 MSAA 시험은 인식 경로 및 자동화 계약 검증입니다. 실제 사내 앱에서 전체 녹화·재생 성공을 뜻하지 않습니다.
